W-H 浏览器采集插件 v0.1.130

安装方法（Edge）：
1. 将本 ZIP 完整解压到一个固定文件夹，不要直接在压缩包内打开。
2. 在 Edge 地址栏输入 edge://extensions/ 并回车。
3. 打开页面左侧的“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择包含 manifest.json 的解压文件夹。
5. 先启动体验版工作台。
6. 打开插件弹窗，工作台地址固定为 http://127.0.0.1:8010。
7. 从工作台“每日运营 → 插件连接”复制当前连接码，粘贴后点击“连接插件”。

说明：
- 工作台地址固定为 http://127.0.0.1:8010，不需要每次修改。
- 连接码随工作台启动生成；工作台重启后若连接失效，重新复制当前连接码即可。
- 插件只读取当前支持页面并把采集结果发送到本机 W-H 工作台。
- 1688 列表页左下角显示“整页采集（万邦）”：扩展更新、重载或重新连接后会自动修复已打开页面的采集入口，不需要手动刷新。扫描直接读取每个商品卡外层 `detail.m.1688.com/page/index.html?offerId=...` 标签，并兼容商品详情链接和“找相似”链接。插件只把链接交给后台登记与查重；随后在工作台“每日选品 → 插件采集”选中批次并点击“启动万邦采集”。启动失败的批次可以再次点击启动，万邦成功后才写入产品处理并计入新建或刷新。
- Temu 商品采集新增页面结构兜底：读取商品主轮播中 `img` 与 CSS `background-image` 图片（包括暂时移出可视区的轮播项），最多保留 24 张；读取“颜色、尺寸、容量、规格、款式、型号、包装”等规格标题及相邻选项文字和规格图。多维规格会按页面真实维度生成组合（例如颜色 × 尺码），同一颜色的规格图会复用到该颜色的各尺码 SKU；数量超出 200 时仍保留每条 SKU 的完整属性维度。促销商品从 `#goods_price` 语义区域读取当前成交价，排除划线原价和“今天支付”等分期金额，并保留 USD/CAD/CNY 币种，工作台不再将美元显示为人民币。SKU 通过 `role="radio"`、`aria-label` 及其子节点图片 URL 识别，重复的页面/接口 SKU 会合并。动态 class 不作为固定识别条件，推荐位、评价图、视频封面和售后服务图会被排除。
- 扩展重载或升级后会自动修复已经打开的 Temu、1688、Alibaba、拼多多和 Amazon 商品页采集按钮；后台运行异常会直接显示具体原因，不再只显示笼统的“采集失败”。
- Temu 与 Alibaba 列表页仍使用原“批量采集本页”流程；单品采集入口和后端入池协议不变。
