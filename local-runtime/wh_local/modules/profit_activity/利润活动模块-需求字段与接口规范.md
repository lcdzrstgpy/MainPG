# 利润活动模块：需求、字段、存储与接口规范

版本：v1.0  
适用范围：`profit_activity` 本地后端模块，以及后续与客户、产品库、选品、活动运营模块的集成。  
接口前缀：`/api/v1/profit-activity`

---

## 1. 模块边界

利润活动模块负责以下业务：

1. 按站点计算单品利润。
2. 保存可版本化的利润参数。
3. 将单品利润计算结果归档为“在档产品”。
4. 支持在档产品查询、编辑、图片/货源管理与删除。
5. 支持 Excel 产品资料预览、重复检测、确认导入。
6. 根据在档产品利润，过滤活动报名 Excel，输出“可申报”和“剔除”结果文件。

不负责的业务：用户认证、公司/团队主数据、产品主数据的唯一来源、外部平台报名提交。上述能力由其他模块提供或通过接口对接。

## 2. 通用字段与约定

| 字段 | 类型 | 规则 | 说明 |
| --- | --- | --- | --- |
| `site` / `site_code` | `string` | `US`、`CO`、`EC` | 站点。旧界面使用 `site`，内部兼容 `site_code`。 |
| `skc` | `string(128)` | 非空，建议大写、去首尾空格 | 产品主标识；当前唯一范围为 `site + skc`。 |
| 金额 | `Decimal` / `NUMERIC(12,4)` | 保留 4 位小数 | 不使用二进制浮点数保存金额。API 可返回 JSON number 或字符串。 |
| 比率 | `Decimal` / `NUMERIC(10,6)` | 范围 `0~1` | 例如 `0.2` 表示 20%。前端显示时乘 100。 |
| 时间 | `datetime` | UTC 存储，ISO-8601 输出 | 例如 `2026-08-04T01:48:05Z`。 |
| 图片路径 | `string` | 仅保存受控本地路径 | 不保存 Base64；通过图片接口读取。 |
| `visibility` | `string` | `private` / `shared` | 当前默认 `shared`；与公司权限接入后用于可见性判断。 |
| `created_by` | `integer` | 用户 ID | 当前本地模式默认 `1`；接入客户模块后必须使用认证用户 ID。 |
| `can_edit` | `boolean` | API 派生字段 | 前端用于判断编辑/删除按钮是否可用，不建议持久化。 |

### 2.1 站点利润规则

| 站点 | 首程费用 | 尾程费用 | 运费补贴 |
| --- | --- | --- | --- |
| `US` | `重量KG × us_first_mile_rate + us_first_mile_fixed` | 按重量梯度，超过 2KG 按 63 | 售价不高于 171 时使用 `shipping_subsidy` |
| `CO` | `重量KG × co_first_mile_rate + co_first_mile_fixed` | 固定 24 | 售价不高于 171 时使用 `shipping_subsidy` |
| `EC` | `重量KG × ec_first_mile_rate + ec_first_mile_fixed` | `ec_end_fee` | 售价不高于 `ec_shipping_subsidy_price_limit` 时使用 `ec_shipping_subsidy` |

计算结果：

```text
total_cost  = cost_price + domestic_fee + shipping_cost + end_fee
gross_profit = selling_price + shipping_subsidy - total_cost
net_profit = gross_profit × (1 - refund_rate) - total_cost × refund_rate
profit_rate = net_profit / total_cost
```

活动资格规则：`net_profit >= activity_min_net_profit` **或** `profit_rate >= activity_profit_rate_threshold` 即为可申报。

## 3. 数据库存储设计

数据库：SQLite，WAL 模式。默认文件建议为：

```text
real-workbench/employee_workbench/data/profit_activity.db
```

### 3.1 `profit_activity_settings`：利润设置

单例表，当前使用 `id = 1`。如后续按公司/工作区分别维护设置，应将唯一键改为 `workspace_id` 或 `company_id`。

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `id` | `INTEGER PK` | `1` | 单例主键。 |
| `revision` | `INTEGER` | `0` | 乐观锁版本；更新时客户端应提交预期版本。 |
| `save_root` | `TEXT` | 空 | 本地输出、资产保存根目录；建议后续移动至系统配置模块。 |
| `domestic_fee` | `NUMERIC(12,4)` | `2.5` | US/CO 国内操作费。 |
| `shipping_subsidy` | `NUMERIC(12,4)` | `21` | US/CO 运费补贴。 |
| `refund_rate` | `NUMERIC(10,6)` | `0.05` | US/CO 退款率。 |
| `us_first_mile_rate` | `NUMERIC(12,4)` | `72` | US 首程每 KG。 |
| `us_first_mile_fixed` | `NUMERIC(12,4)` | `5` | US 首程固定费。 |
| `co_first_mile_rate` | `NUMERIC(12,4)` | `80` | CO 首程每 KG。 |
| `co_first_mile_fixed` | `NUMERIC(12,4)` | `0` | CO 首程固定费。 |
| `ec_domestic_fee` | `NUMERIC(12,4)` | `2.5` | EC 国内操作费。 |
| `ec_shipping_subsidy` | `NUMERIC(12,4)` | `15` | EC 运费补贴。 |
| `ec_shipping_subsidy_price_limit` | `NUMERIC(12,4)` | `120` | EC 补贴适用售价上限。 |
| `ec_first_mile_rate` | `NUMERIC(12,4)` | `108` | EC 首程每 KG。 |
| `ec_first_mile_fixed` | `NUMERIC(12,4)` | `0` | EC 首程固定费。 |
| `ec_end_fee` | `NUMERIC(12,4)` | `27` | EC 尾程固定费。 |
| `ec_refund_rate` | `NUMERIC(10,6)` | `0.05` | EC 退款率。 |
| `activity_min_net_profit` | `NUMERIC(12,4)` | `8` | 活动最低净利润。 |
| `activity_profit_rate_threshold` | `NUMERIC(10,6)` | `0.2` | 活动最低利润率。 |
| `rule_version` | `INTEGER` | `2` | 活动筛选规则版本；API 同时输出别名 `activity_filter_rule_version`。 |
| `updated_at` | `DATETIME` | 当前时间 | 最后修改时间。 |

## 4. 文件存储设计

建议路径：

```text
{PROFIT_ACTIVITY_OUTPUT_DIR 或 save_root}/
├── assets/{site}/{skc}/product/     # 商品主图
├── assets/{site}/{skc}/source/      # 货源截图
├── {site}_product_catalog.xlsx      # 商品档案导出
├── eligible_{token}.xlsx            # 可申报活动结果
└── excluded_{token}.xlsx            # 剔除活动结果
```

文件路径只在本地存储中使用。若后续接入对象存储，应增加字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `storage_backend` | `string` | `local`、`s3`、`oss` 等。 |
| `storage_key` | `string` | 对象存储键。 |
| `sha256` | `string(64)` | 文件去重、完整性校验。 |
| `content_type` | `string` | 例如 `image/png`。 |
| `size_bytes` | `integer` | 文件大小。 |

## 5. 产品资料 Excel 字段

上传接口支持 `.xlsx`、`.xlsm`。首行必须为表头，支持中英文别名。

| 标准字段 | 支持表头示例 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- | --- |
| `skc` | `SKC`、`SKC ID`、`商品ID`、`商品编号` | 是 | 文本 | 产品唯一标识。 |
| `selling_price` | `售价`、`销售价`、`selling price`、`price` | 是 | 数字 | 大于 0。 |
| `cost_price` | `成本`、`成本价`、`cost price` | 是 | 数字 | 大于 0。 |
| `weight_kg` | `重量`、`重量KG`、`weight kg` | 是 | 数字 | 大于 0。 |
| `note` | `备注`、`说明`、`note` | 否 | 文本 | 产品备注。 |
| `source_url` | `货源`、`货源链接`、`采购链接`、`source url` | 否 | 文本 | 货源 URL 或描述。 |

导入预览行字段：

| 字段 | 说明 |
| --- | --- |
| `row_id` | `工作表名:行号`，确认导入时使用。 |
| `worksheet` / `row_number` | 原始 Excel 位置。 |
| `status` | `ready` 或 `blocked`。 |
| `warnings` | 可继续导入的提醒，例如 `duplicate_skc`。 |
| `blockers` | 阻止导入原因，例如 `missing_skc`、`invalid_cost_price`。 |
| `product_id` / `product_id_label` | 当前为 SKC 兼容展示字段。 |
| `is_duplicate` | 当前站点下是否已有同 SKC。 |
| `has_product_image` / `has_source_image` | 当前 Excel 预览图片状态。 |

冲突策略：

| `on_conflict` | 行为 |
| --- | --- |
| `skip` | 同站点同 SKC 已存在时跳过。 |
| `replace` | 用本次 Excel 的价格、成本、重量、备注、货源覆盖旧记录。 |

## 6. HTTP 接口规范

### 6.1 设置与利润计算

#### `GET /profit-activity/settings`

返回完整设置对象，字段为第 3.1 节中的设置字段；同时返回 `activity_filter_rule_version`。

#### `PUT /profit-activity/settings`

支持两种请求格式：

**旧界面扁平格式**

```json
{
  "save_root": "E:/profit-output",
  "domestic_fee": 2.5,
  "shipping_subsidy": 21,
  "activity_min_net_profit": 8,
  "activity_profit_rate_threshold": 0.2
}
```

**带乐观锁的新格式**

```json
{
  "expected_revision": 3,
  "settings": {
    "domestic_fee": 2.5,
    "shipping_subsidy": 21,
    "refund_rate": 0.05,
    "us_first_mile_rate": 72,
    "us_first_mile_fixed": 5,
    "co_first_mile_rate": 80,
    "co_first_mile_fixed": 0,
    "ec_domestic_fee": 2.5,
    "ec_shipping_subsidy": 15,
    "ec_shipping_subsidy_price_limit": 120,
    "ec_first_mile_rate": 108,
    "ec_first_mile_fixed": 0,
    "ec_end_fee": 27,
    "ec_refund_rate": 0.05,
    "activity_min_net_profit": 8,
    "activity_profit_rate_threshold": 0.2,
    "rule_version": 2
  }
}
```

#### `POST /profit-activity/calculate`

请求：

```json
{
  "site": "US",
  "selling_price": 100,
  "cost_price": 10,
  "weight_kg": 0.2
```

返回核心字段：

#### `POST /profit-activity/products`

内容类型：`multipart/form-data`（图片上传）或 `application/json`（无图片）。

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `skc` | 是 | SKC。 |
| `site` | 否 | 默认 `US`。 |
| `selling_price` | 是 | 售价。 |
| `cost_price` | 是 | 成本。 |
| `weight_kg` | 是 | 重量。 |
| `note` | 否 | 备注。 |
| `visibility` | 否 | 默认 `shared`。 |
| `source_url` | 否 | 主货源链接。 |
| `source_groups_json` | 否 | 货源组 JSON。 |
| `image` | 否 | 商品主图文件。 |
| `source_image` | 否 | 第一组货源图文件。 |
| `source_group_image_{N}` | 否 | 第 N 个货源组的图片，可重复提交。 |

返回：`{ "product": ProfitActivityProduct }`。

#### `POST /profit-activity/products/{skc}/update`

与创建接口字段一致，路径中的 `skc` 为目标产品标识。用于旧界面 `multipart/form-data` 编辑。

#### `PATCH /profit-activity/products/{skc}`

内容类型：`application/json`。支持字段：`site`、`selling_price`、`cost_price`、`weight_kg`、`note`、`visibility`、`source_url`、`source_groups_json`。

#### `DELETE /profit-activity/products/{skc}?site=US`

删除单个产品。返回：

```json
{ "status": "deleted", "skc": "SKC-001", "site": "US" }
```

#### `DELETE /profit-activity/products`

批量删除请求：

```json
{ "site": "US", "skcs": ["SKC-001", "SKC-002"] }
```

#### `GET /profit-activity/products/{skc}/image`

查询参数：`site`、`kind=product|source`、`group`、`index`。返回图片二进制。

## 7. 与其他模块的交互规范

### 7.1 客户/权限模块

建议利润活动请求上下文统一提供：

```json
{
  "user_id": 1001,
  "username": "alice",
  "company_id": 2001,
  "workspace_id": 3001,
  "permissions": ["profit_activity.read", "profit_activity.write", "profit_activity.delete"]
}
```

需要替换当前本地默认值的字段：`created_by`、`created_by_username`、`workspace_id`、`workspace_code`、`workspace_name`、`is_owner`、`can_edit`。

权限规则建议：

| 操作 | 建议权限 |
| --- | --- |
| 查询本人产品 | `profit_activity.read` |
| 查询本公司共享产品 | `profit_activity.company_read` |
| 新增/编辑本人产品 | `profit_activity.write` |
| 编辑他人共享产品 | `profit_activity.company_write` |
| 删除本人产品 | `profit_activity.delete` |
| 删除他人产品 | `profit_activity.company_delete` |

### 7.2 产品库模块

利润活动可作为产品库的“利润快照来源”，但产品主数据应由产品库维护。

建议产品库提供：

```text
GET /api/v1/product-library/products?site=US&skcs=SKC-001,SKC-002
```

建议返回最少字段：`product_id`、`skc`、`spu`、`site`、`title`、`main_image_asset_id`、`source_url`、`owner_company_id`、`status`。

利润活动建议增加未来外键字段：

| 字段 | 说明 |
| --- | --- |
| `product_id` | 产品库主键。 |
| `product_version` | 归档时产品版本。 |
| `main_image_asset_id` | 统一资产库图片 ID。 |

### 7.3 选品/核价货源模块

输入给利润活动的推荐字段：`skc`、`site`、`selling_price`、`cost_price`、`weight_kg`、`source_url`、`source_groups`、`source_confidence`。

利润活动输出给选品模块的推荐字段：`net_profit`、`profit_rate`、`total_cost`、`settings_revision`、`calculation_hash`、`activity_eligible`、`activity_reason_code`。

### 7.4 活动运营模块

活动运营模块应仅消费筛选结果，不直接修改利润快照。

建议输出契约：

```json
{
  "site": "US",
  "skc": "SKC-001",
  "decision": "eligible",
  "reason_code": "net_profit_and_profit_rate_passed",
  "net_profit": 57.05,
  "profit_rate": 0.98532,
  "settings_revision": 4,
  "rule_version": 2
}
```

## 8. 合并与数据库迁移建议

1. 不要以 `skc` 单列作为全局唯一键；至少使用 `workspace_id + site_code + skc`。
2. 金额和比率统一使用 `NUMERIC`，禁止把价格、成本、利润存为 `TEXT`。
3. 真实用户、公司、工作区字段由客户模块统一定义，利润活动仅引用其 ID。
4. 图片建议逐步迁移到统一资产表；在迁移期间保留 `image_path`、`source_image_path` 的兼容输出。
5. 所有导入、过滤任务应保留任务状态和结果快照，便于断点查询和审计。
6. 数据库迁移应使用版本化 migration；新列必须提供默认值或可空策略，保证旧 SQLite 数据库可升级。
7. 导入预览会话、临时 Excel、筛选输出应设置保留周期和清理任务。
