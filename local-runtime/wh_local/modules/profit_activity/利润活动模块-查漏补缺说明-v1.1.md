# 利润活动模块：查漏补缺说明（v1.1）

本说明记录与原利润活动界面逐项对照后，在本地 FastAPI + SQLite（WAL）实现中补齐的行为。这里的“兼容”只表示请求、响应和业务结果可对接；实现仍使用本项目的 `profit_activity` 模块分层与本地存储，不复制原项目目录或运行时路径。

## 路由入口

两套路由共用同一个 `ProfitActivityService` 与同一份 SQLite 数据：

| 路由前缀 | 用途 |
| --- | --- |
| `/api/v1/profit-activity` | 本项目原有版本化接口 |
| `/profit-activity` | 原利润活动前端兼容入口 |

因此旧界面请求 `/profit-activity/settings`、`/profit-activity/products` 等不会再因为仅存在 `/api/v1` 前缀而得到 404。该别名只增加访问路径，不复制数据，也不影响其他 `main.py` 已挂载模块。

## 对照结果

| 界面板块 | 对应接口 | 本次确认/补齐的逻辑 |
| --- | --- | --- |
| 保存目录与默认参数 | `GET/PUT /settings` | 保存前创建并写入探针文件验证目录可写；空目录值回退到本地默认输出目录；所有费率、补贴、阈值在保存时校验非负/比例范围；保留 `activity_filter_rule_version` 别名。 |
| 单品利润 | `POST /calculate` | US、CO、EC 使用当前保存的站点公式；返回 `calculation`、`preview` 和配置快照。 |
| 单品入档及货源 | `POST /products`、`POST /products/{skc}/update`、`PATCH /products/{skc}` | 保存 SKC、售价、成本、重量、备注、货源链接、商品主图及多货源组。兼容原界面的 `source_group_images_{N}`，同时兼容早期 singular 字段 `source_group_image_{N}`。 |
| 查询产品 | `GET /products` | `skcs` 同时支持逗号、中文逗号、空格、换行分隔；保留 `scope` 和 `owner_user_id` 回传字段，便于后续权限模块接入。 |
| 产品库 | `GET/DELETE /products`、`POST /catalog/rebuild` | 支持单个/批量删除及按站点下载商品档案；档案写入设置的保存目录。 |
| 资料上传 | `POST /products/import/preview`、`POST /products/import/confirm`、`GET /products/import/tasks/{task_id}` | 预览校验 SKC、售价、成本、重量、重复 SKC；确认导入支持 `skip`/`replace`。若 Excel 内嵌图片，按锚定行提取并可由预览图片接口读取；确认导入时会保存为产品/货源图片。 |
| Excel 预览图片 | `GET /products/import/{import_id}/image/{row_id}` | 不再固定返回 404；根据预览行的 `product_image_path` 或 `source_image_path` 返回图片。无图片或行不存在才返回 404。接受 `variant=original|thumb|thumbnail|preview` 以兼容原页面，目前均返回原图。 |
| 活动过滤 | `POST /activity-filter`、任务查询、下载 | 从活动模板识别 SKC、活动名称、活动申报价和站点；同一 SKC/活动取最低申报价重新计算利润，以“净利润达标 **或** 利润率达标”判定；输出保留原工作表结构的可申报模板，并同步删除关联活动库存表中的孤儿 SPU 行，同时生成单独的剔除明细 Excel。 |

## Excel 字段补充

### 产品资料导入

必填业务列：`SKC`、售价（`selling price`）、成本（`cost`）、重量 KG（`weight kg`）。可选列：备注、货源链接、商品主图、货源图。中英文表头别名均受支持。

预览返回行增加以下字段，不改变已有字段：

| 字段 | 说明 |
| --- | --- |
| `has_product_image` / `has_source_image` | Excel 行是否解析到内嵌图片 |
| `product_image_path` / `source_image_path` | 本地预览文件路径，仅供该本地运行时读取；不应作为跨模块业务主键 |

### 活动 Excel

至少应包含 SKC 列。要按真正活动价格筛选，应再提供“活动申报价”（或 `activity price`）列；缺少或无效价格的行会进入剔除明细，原因码为 `invalid_activity_price`。可选“站点”列与当前请求站点不一致时，原因码为 `site_mismatch`。

活动筛选 `reason_code` 包含：

- `net_profit_and_profit_rate_passed`
- `net_profit_passed`
- `profit_rate_passed`
- `net_profit_and_profit_rate_below_threshold`
- `missing_product`
- `invalid_activity_price`
- `site_mismatch`

## 本地文件落点

`save_root` 配置优先；未配置时使用 `real-workbench/employee_workbench/outputs/profit_activity/`。其下产生：

```text
{save_root}/
├── assets/{site}/{skc}/product/        # 单品主图
├── assets/{site}/{skc}/source/         # 货源图
├── assets/{site}/import_*/preview_*/   # 导入预览临时图片
├── {site}_product_catalog.xlsx         # 商品档案
└── activity_outputs/
    ├── eligible_{token}.xlsx           # 保留原模板、删除不合格行
    └── excluded_{token}.xlsx           # 剔除明细及原因
```

这些绝对路径只属于本地运行时响应，跨模块交互应传递 `site + skc + 利润快照字段`，而不是依赖本机文件路径。
