# 前端目录职责说明

## 根目录

| 目录 | 作用 |
| --- | --- |
| `public/` | 不参与打包处理的静态资源，例如应用图标、下载模板和帮助图片。 |
| `src/` | 前端源代码根目录。业务页面不得直接堆放在此层。 |
| `tests/` | 跨模块的端到端、集成测试与固定测试数据。模块单元测试仍放在各模块的 `tests/`。 |
| `docs/` | 前端架构、接口对接和开发约定文档。 |

## `src/` 下的基础目录

| 目录 | 作用 |
| --- | --- |
| `app/` | 应用启动、路由装配、全局 Provider、主框架和导航配置。 |
| `modules/` | 按业务边界拆分的页面与业务逻辑。模块名与后端模块使用同一 snake_case 名称。 |
| `shared/` | 可复用且不属于任何业务模块的 API 客户端、通用组件、Hooks、工具、类型和样式。 |
| `runtime/` | 本地运行时连接状态、健康检查、桌面/浏览器运行环境适配。 |
| `transport/` | HTTP 请求封装、查询缓存、下载上传及错误标准化；不得包含具体业务接口。 |
| `contracts/` | 由后端接口契约生成或维护的共享 DTO 类型，避免页面重复定义请求/响应字段。 |

## `src/modules/{module}/` 标准层级

所有已启用模块统一保留以下目录，避免页面、请求和状态集中在一个目录：

| 子目录 | 作用 |
| --- | --- |
| `api/` | 该模块专属 API 请求、参数转换与响应适配。 |
| `pages/` | 路由页面与页面级组合逻辑。 |
| `components/` | 该模块内部复用的展示和交互组件。 |
| `state/` | 状态管理、查询键、表单状态与视图模型。 |
| `types/` | 模块内部领域类型；公共 API DTO 应优先放入 `src/contracts/`。 |
| `tests/` | 模块单元测试、组件测试与接口模拟。 |
| `styles/` | 模块独立样式、设计变量覆盖和页面布局样式。 |

## 已启用业务模块

| 模块目录 | 对应后端/业务 | 主要职责 |
| --- | --- | --- |
| `customer/` | `wh_local/customer` | 登录、会话、员工与公司/工作区上下文。 |
| `basic_settings/` | `modules/basic_settings` | 系统配置、外部服务配置和本地参数。 |
| `dashboard/` | `modules/dashboard` | 工作台概览、任务摘要和快捷入口。 |
| `daily_selection/` | `data_collection` | 每日选品采集、候选结果、入池确认与产品处理交接。 |
| `product_processing/` | `modules/product_processing` | 草稿池、Excel 导入、商品处理任务、结果下载。 |
| `profit_activity/` | `modules/profit_activity` | 利润公式、产品入档、资料导入、活动过滤和档案下载。 |
| `price_verification/` | `price_verification` | 价格核验、记录查询与异常处理。 |

## 预留业务模块

以下目录与团队当前总体模块规划保持一致，后端服务落地时再按相同标准补齐内部子目录：

| 模块目录 | 预留职责 |
| --- | --- |
| `commercial_sourcing/` | 商业货源、供应商与采购链接管理。 |
| `daily_operations/` | 日常运营任务与执行记录。 |
| `help_diagnostics/` | 帮助中心、运行诊断和故障提示。 |
| `local_export/` | 本地导出历史、下载记录与文件管理。 |
| `price_source/` | 价格来源、比价输入和来源配置。 |
| `product_library/` | 跨模块产品主数据与产品档案。 |
| `product_workbench/` | 产品编辑、审核与批量工作台。 |
| `sync_status/` | 模块同步状态、失败重试和日志入口。 |

## 文档存放约定

| 文档类型 | 存放位置 |
| --- | --- |
| 全局前端架构/目录说明 | `web-frontend/docs/` |
| 某模块接口映射与字段说明 | `web-frontend/docs/modules/{module}.md` |
| 某模块开发约定或特殊说明 | `web-frontend/src/modules/{module}/README.md` |
| 跨模块 UI/交互规范 | `web-frontend/docs/standards/` |
