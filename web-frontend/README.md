# 智能电商平台前端工程骨架

本目录与仓库根目录的 `local-runtime/` 平行，作为独立的 Web 前端工程预留位置。

当前阶段已实现可运行的 React/Vite 演示外壳：登录/注册页、平台主框架、侧边栏、标签导航和个人中心均为本地演示状态，不会调用后端接口。

建议后续沿用原工作台的技术方向：React、TypeScript、Vite、CSS Modules（或统一样式方案）。每个功能模块通过 `src/modules/{业务名}/api/` 调用后端，不直接跨模块引用页面或状态。

目录职责见 [docs/目录职责说明.md](docs/目录职责说明.md)。

演示框架的运行方法与团队嵌入约定见 [docs/前端演示框架协作说明.md](docs/前端演示框架协作说明.md)。
