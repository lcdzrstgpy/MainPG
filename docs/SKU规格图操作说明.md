# SKU 规格图操作说明（给用户看的）

> 一句话结论：**什么都不改、直接导出，出来的图就是没有中文的。**
> 想去掉中文不用你操心；真正需要你动手的，是「想用规格原图」的时候。

---

## 一、先搞懂系统默认在做什么

导出时，SKU 规格图列（店小秘「预览图」/ 妙手「颜色图・预览图」）按下面的顺序取值：

```
① 你手动逐个换过的图          ← 有就优先用
② 「全用主图」策略            ← 用 AI 处理后的商品主图
③ 「自动」策略（默认）        ← 按可用性判断结论决定
④ 「规格原图」策略            ← 用来源链接的原始规格图
```

第 ③ 步「自动」的规则很关键：

| 可用性判断结论 | 自动策略实际取图 |
|---|---|
| 判定干净（且结论未失效） | ✅ 用规格原图 |
| 判定有问题 / 没判定过 | ⚠️ 回退商品主图 |

**所以默认情况下：没跑过判定的商品，会全部回退主图——这是安全兜底，不是故障。**

## 二、两种用法

### 路一：图省事（推荐大多数人）

**什么都不用改，直接导出。**

导出前看一眼面板上有没有**黄色提示条**：

| 你看到什么 | 说明什么 | 你该怎么做 |
|---|---|---|
| 没有黄条 | 判定干净，规格原图会被用上 | 直接导出 |
| 「本商品尚未做过『SKU 规格图可用性判断』…」 | 全部会回退主图 | 想用原图 → 先跑一次可用性判断；不想用原图 → 直接导出 |
| 「…规格原图素材不可用…」 | 素材本身有问题 | 直接导出（会用主图） |
| 「…判定结论为『不可用』…」 | 图上检出中文 | 直接导出（会用主图） |

### 路二：想精细控制（逐个 SKU 决定）

进「**管理 SKU 规格图**」面板，每张 SKU 卡片可以：

| 我想干嘛 | 点哪里 |
|---|---|
| 这个 SKU 自己挑一张图 | 卡片上的「**换图**」 |
| 这个 SKU 用商品主图 | 把卡片切到「**全用主图**」 |
| 这个 SKU 不要了 | 「**删除规格**」（导出时这行不出现） |
| 给整条链接的所有 SKU 选图 | 底部的「**批量换图**」 |

## 三、三个策略按钮的区别（最容易搞混）

| 按钮 | 大白话 | 中文风险 |
|---|---|---|
| **规格原图** | 「我就要原始图，带中文我也认」 | 🔴 高，慎用 |
| **全用主图** | 「这条链接所有 SKU 都用商品主图」 | 🟢 无，最安全 |
| **自动**（默认） | 「你帮我判断，干净的用原图，有问题用主图」 | 🟢 无，推荐 |

> 三个按钮是**互斥**的，一次只能选中一个。它们改的是「整条链接的策略」，不是单个 SKU 的图。

## 四、两个必须知道的坑

### 坑 1：改完不保存 = 白改

面板头部会显示当前状态：

| 徽标 | 含义 |
|---|---|
| 🟡 **待保存** | 只是改了本地，**还没生效** |
| 🟢 **已生效** | 已经写进草稿，导出会按这个走 |

看到「待保存」必须点「**保存预检修改**」，或者直接「**完成预审并导出**」，才会真正生效。

### 坑 2：「已换图 0 / 6」不代表没换

这个计数只统计你**手动逐个挑图**的数量，`6` 是单条链接的上限。

**切换策略（比如点「全用主图」）不占这个名额**，所以计数不动是正常行为。

## 五、缩略图怎么看

卡片上的缩略图会**跟着当前策略变**：

| 你看到 | 含义 |
|---|---|
| 图上角标「**主图**」+ 徽标「**导出用主图**」 | 这个 SKU 导出时会用商品主图 |
| 徽标「**已换图**」 | 你手动换过，用你换的那张 |
| 徽标「**待审核原图**」 | 原图检出中文，建议重新锚定后再换图 |
| 徽标「**已删除**」 | 这个 SKU 导出时不出现 |

## 六、常见问题

**Q：我选了「全用主图」，为什么「已换图」还是 0 / 6？**
A：正常。策略切换不占手动换图名额，见「坑 2」。

**Q：我选了「自动」，导出结果却全是主图？**
A：说明这条链接**没跑过「SKU 可用性判断」**，或者判定结论是「不可用」。看面板上有没有黄色提示条——它会直接告诉你原因。

**Q：改了策略但导出没变？**
A：大概率是「待保存」状态，没点保存。见「坑 1」。

**Q：导出后规格图里有中文怎么办？**
A：说明这条链接被切到了「规格原图」策略，或者某个 SKU 被手动换成了带中文的图。改成「自动」或「全用主图」再导出。

**Q：判定干净了，但我不想要原图，能用主图吗？**
A：可以。把这条链接单独切到「全用主图」即可。

---

## 七、速查表

```
想省事      → 什么都不改，直接导出（默认无中文）
想用原图    → 先跑「SKU 可用性判断」，判定干净后自动会用
想精准控制  → 进面板逐个 SKU 换图 / 删除，改完记得保存
想绝对安全  → 全切「全用主图」
```
