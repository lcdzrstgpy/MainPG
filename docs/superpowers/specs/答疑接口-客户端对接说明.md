# 答疑接口 · 客户端对接说明

> 服务端已上线：`https://workbench.haocoming.top/qa`
> 本文面向客户端开发，覆盖鉴权、请求响应、流式解析、错误处理与联调方式。

---

## 一、总体说明

- 悬浮窗提问 → 客户端调本接口 → 服务端检索知识库/实时价目 → 调用豆包生成 → 流式返回。
- **客户端不接触任何模型 API Key**，也不要直连豆包。所有模型调用在服务端完成。
- 身份复用客户端现有的 `wh_auth_*` 登录 token，不需要新做一套账号。

### 接口一览

| 用途 | 方法与路径 |
|---|---|
| 提问（主接口） | `POST https://workbench.haocoming.top/qa/chat` |
| 引导问题 | `GET https://workbench.haocoming.top/qa/suggestions` |
| 答案反馈 | `POST https://workbench.haocoming.top/qa/feedback` |
| 健康检查 | `GET https://workbench.haocoming.top/qa/health` |

除 `health` 外都需要带 `Authorization` 头。

---

## 二、鉴权

```
Authorization: Bearer <客户端现有的 wh_auth_* token>
```

- token 无效或过期 → `401`。
- 未登录时请把悬浮窗入口置灰并提示「请先登录」，不要发请求。
- 服务端会向客户认证服务校验 token，结果缓存 60 秒，不会拖慢每次提问。

## 三、提问接口

### 3.1 请求

```
POST https://workbench.haocoming.top/qa/chat
Authorization: Bearer <token>
Content-Type: application/json
```

```json
{
  "session_id": "c1f0a6b4-3f2e-4b1a-9d7c-6e5f4a3b2c1d",
  "message": "浏览器插件怎么安装",
  "stream": true,
  "context": {
    "client_version": "1.6.5",
    "platform": "windows",
    "page": "plugin"
  }
}
```

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `session_id` | 是 | string | 悬浮窗打开时生成一次 UUID，整个会话复用。服务端据此保留最近 3 轮上下文 |
| `message` | 是 | string | 用户问题，**上限 1000 字**，超出返回 `413` |
| `stream` | 否 | bool | 默认 `true`。设为 `false` 时返回一次性 JSON，适合先打通链路 |
| `context` | 否 | object | 仅用于日志与问题定位，不参与鉴权与计费 |

### 3.2 流式响应（`stream: true`）

响应类型 `text/event-stream`，按 `\n\n` 分隔事件块：

```
event: meta
data: {"request_id":"r_8f2c1d3a","intent":"tutorial","cached":false}

event: delta
data: {"text":"浏览器插件安装步骤如下："}

event: delta
data: {"text":"\n1. 打开官网下载压缩包"}

event: citation
data: {"title":"四、安装并连接浏览器插件","url":"https://my.feishu.cn/wiki/..."}

event: done
data: {"finish":"stop","latency_ms":2140}
```

| 事件 | 出现次数 | 用途 |
|---|---|---|
| `meta` | 1 次，最先 | 取 `request_id` 留存（反馈接口要用）；`intent` 表示判定类型（`price` / `tutorial` / `cache`）；`cached` 表示命中缓存 |
| `delta` | 多次 | 追加文本到气泡 |
| `citation` | 0～3 次 | 渲染为答案下方的引用链接 |
| `done` | 1 次，最后 | 结束加载态；`latency_ms` 可用于埋点 |

**注意**：`delta` 的文本是增量片段，不是完整句子，必须逐段 append，不能整体替换。

### 3.3 非流式响应（`stream: false`）

```json
{
  "request_id": "r_8f2c1d3a",
  "answer": "浏览器插件安装步骤如下：1. … 2. …",
  "citations": [
    { "title": "四、安装并连接浏览器插件", "url": "https://my.feishu.cn/wiki/..." }
  ],
  "intent": "tutorial",
  "fallback": false,
  "latency_ms": 2140
}
```

`fallback: true` 表示知识库里没找到明确答案，返回的是兜底话术（引导用户看手册或提交反馈）。**这属于正常返回**，按普通答案渲染即可，不要当成错误。

## 四、错误处理

| HTTP | 含义 | 客户端表现 |
|---|---|---|
| `400` | `message` 为空 | 提示用户输入内容 |
| `401` | token 无效或过期 | 提示重新登录，保留输入框内容 |
| `413` | 问题超过 1000 字 | 提示精简后重试 |
| `429` | 超出限流 | 显示「提问太频繁，请 X 秒后再试」，X 取自响应头 `Retry-After` |
| `5xx` | 服务异常 | 显示「答疑服务暂时不可用」，保留输入内容 |

限流规则：**单账号 10 次/分钟、200 次/天**。

## 五、参考实现（JavaScript）

```js
export async function askQA({ token, question, sessionId, onDelta, onCitation, onDone }) {
  const resp = await fetch("https://workbench.haocoming.top/qa/chat", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      Authorization: `Bearer ${token}`,
    },
    body: JSON.stringify({
      session_id: sessionId,
      message: question,
      stream: true,
      context: { client_version: "1.6.5", platform: "windows" },
    }),
  });

  if (resp.status === 401) throw new Error("登录已失效，请重新登录");
  if (resp.status === 413) throw new Error("问题太长了，请精简一下");
  if (resp.status === 429) {
    const wait = resp.headers.get("Retry-After") || "60";
    throw new Error(`提问太频繁，请 ${wait} 秒后再试`);
  }
  if (!resp.ok) throw new Error("答疑服务暂时不可用");

  const reader = resp.body.getReader();
  const decoder = new TextDecoder();
  let buffer = "";
  let requestId = "";

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    buffer += decoder.decode(value, { stream: true });

    let index;
    while ((index = buffer.indexOf("\n\n")) >= 0) {
      const block = buffer.slice(0, index);
      buffer = buffer.slice(index + 2);

      const eventLine = block.split("\n").find((line) => line.startsWith("event: "));
      const dataLine = block.split("\n").find((line) => line.startsWith("data: "));
      if (!eventLine || !dataLine) continue;

      const event = eventLine.slice(7).trim();
      const data = JSON.parse(dataLine.slice(6));

      if (event === "meta") {
        requestId = data.request_id;
      } else if (event === "delta") {
        onDelta(data.text);
      } else if (event === "citation") {
        onCitation(data);
      } else if (event === "done") {
        onDone({ requestId, latencyMs: data.latency_ms });
      }
    }
  }
}
```

## 六、UI 上的四条约束

1. **不要自动重试**。请求发出即可能产生模型调用费用，失败请让用户手动再点一次。
2. **不要本地保存模型 Key**，客户端只认 `wh_auth_*`。
3. **引用链接用系统浏览器打开**，不要在应用内嵌 WebView 加载飞书页面（需要登录态，嵌进去会白屏）。
4. **首次接入建议先用 `stream: false`** 跑通请求与鉴权，再切流式。

## 七、联调方式

先用健康检查确认网络通：

```bash
curl https://workbench.haocoming.top/qa/health
# {"ok":true,"model":"doubao-seed-2-1-lite-260915","kb_ready":true,"kb_version":"..."}
```

再验证鉴权与流式（把 `<token>` 换成真实登录 token）：

```bash
curl -N -X POST https://workbench.haocoming.top/qa/chat \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"session_id":"test-1","message":"浏览器插件怎么安装","stream":true}'
```

不带 token 时应返回 `401`，带真 token 应能看到逐段 `delta`。

## 八、待确认事项

1. **客户端技术栈**：如果是 Electron / WebView2 / 浏览器渲染层，浏览器会施加跨域限制，需要服务端给 `/qa/` 加 CORS 头。原生 HTTP 客户端（Qt、.NET HttpClient、Go、Rust）不受影响。
2. **是否需要多轮上下文**：当前服务端按 `session_id` 保留最近 3 轮。若希望每次提问完全独立，需服务端关闭该能力。
3. **免责与引导文案**：兜底话术目前固定为「这个我暂时没有查到明确说明，建议查看《使用手册》或在意见反馈中提交」。如需调整措辞请提前告知。
