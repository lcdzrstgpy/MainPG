# 尺寸画布图标设计

## 目标

修复尺寸画布侧栏图标为空的问题，并让侧栏、页面标题、空状态与主要操作使用同一套现有 iconfont 视觉语言。图标应随当前主题继承颜色，不引入新的字体、图片或外部依赖。

## 选型

主图标使用下载目录现有图标库中的 `icon-column-width`。其水平测量语义最接近商品尺寸标注，也不会像 `icon-arrawsalt` 一样被误解为移动工具，或像 `icon-file-image` 一样仅表达图片管理。

当前 `dimension_canvas` 配置中的 `icon-ruler` 不存在于该图标库，必须替换，不能通过新增空 CSS 类掩盖资源缺失。

## 应用范围

- 侧栏“尺寸画布”：使用 `iconfont icon-column-width`，沿用其它一级模块相同的尺寸、间距、悬停和选中态。
- 尺寸画布页面标题：在标题左侧加入小型主图标徽章，颜色、边框和背景全部使用页面现有主题变量。
- 无批次空状态：用主图标替换原始字符 `↔`，保持现有 72px 图标容器。
- 页面主要操作：导入使用 `icon-upload`，刷新使用 `icon-sync`，交回审核使用 `icon-check-circle`。图标只辅助识别，不替换按钮文字。
- 单商品画布页签：保留现有页签数据合同，不在本次将字符串图标模型改造成 React 节点，避免扩大导航架构变更。

## 视觉与交互规则

- 只使用 `web-frontend/download/font_5219619_sag0ft83mnn` 已提供的类名。
- 图标继承文字颜色，并随默认、夕阳、紫罗兰和钻石主题切换。
- 装饰性图标设置 `aria-hidden="true"`；按钮仍以文字提供可访问名称。
- 页面标题图标不增加动画，避免工具页出现无意义动效。
- 不改变按钮位置、画布布局、数据流程、保存逻辑或路由。

## 验收

- 侧栏展开和收起状态均可看到清晰的尺寸图标。
- 页面标题、空状态和三个主要操作图标显示正常，无缺字方框或空白占位。
- TypeScript 检查与 Vite 生产构建通过。
- 现有前端测试通过，并在本地页面至少检查默认主题与一个非默认主题。

## 范围边界

本次不修改 iconfont 源文件，不新增外部图标包，不重做尺寸画布视觉体系，不调整页签数据结构，也不部署或打包安装程序。
