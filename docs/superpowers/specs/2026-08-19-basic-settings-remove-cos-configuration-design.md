# 下线系统设置中的 COS 配置

## 目标

系统设置页面不再向用户展示、校验或保存腾讯 COS（图床）配置。图床由后端既有的固定配置和运行时策略负责，前端不参与配置。

## 范围

- 删除基础设置页的 COS 图床卡片，包括存储桶、地域、SecretId、SecretKey 与公共媒体地址字段。
- 从基础设置表单、可见性状态和字段校验中删除所有 COS 相关状态与逻辑。
- 前端保存配置时不再在更新载荷中包含 `cos`，也不提交 COS 密钥。
- 保留配置接口响应中的 COS 字段，以保持后端和其他现有调用方兼容。
- 不调整后端的 COS、静态图床或图片上传实现。

## 数据流

页面加载和“重新读取”仍可读取完整的后端系统配置，但只回填当前页面仍支持配置的模型字段。保存时，前端构造的更新载荷仅包含 AI、备用 AI、限制和更新配置；不读取、不复制、也不覆盖 `currentConfig.cos`。

## 错误处理

保留现有 AI 密钥格式校验。COS 相关校验和“公共媒体地址必须使用 HTTPS”校验删除，因此不会再阻止用户保存与图床无关的设置。

## 验证

新增/更新前端测试，证明配置更新载荷不含 `cos` 字段，即使后端当前配置含有 COS 信息。执行前端测试和 TypeScript/Vite 构建，确保设置页可正常编译。
