# 产品库展示核价 SKC 主图

## 背景

核价及货源模块已采集每个 Temu SKC 的 `main_image_url`，并在核价页面直接以该 URL 渲染主图。自动同步产品库时只同步了售价、成本和 1688 货源信息，遗漏了该 SKC 主图，因此产品库的“SKC对应图”列显示“无图”。

## 目标

让产品库展示来自核价及货源的 SKC 主图，并补齐已有核价入库产品；人工上传的产品库主图始终优先。

## 方案

### 数据

- 为产品库记录增加可选字段 `source_main_image_url`，保存核价批次中该 SKC 的 Temu 主图 URL。
- 该字段仅表示外部核价主图；现有 `image_path` 继续表示用户上传并保存在本地的主图。
- 数据库升级使用兼容的新增列方式，旧记录默认空值。

### 同步与回填

- 核价及货源在关联或解除关联后同步产品库时，将批次选择记录的 `main_image_url` 写入 `source_main_image_url`。
- 应用启动时已有的 `sync_all_to_product_library` 回填仍会执行，因此历史的核价入库产品会自动补齐该字段。
- 只更新来源为 `price_verification` 的记录；非核价手工产品不写入此字段。
- 不下载图片、不复制图片字节，继续使用核价模块现有的外链图片来源。

### 展示

产品库“SKC对应图”列按以下优先级显示：

1. `image_path`：人工上传或替换的本地主图，通过现有鉴权图片接口加载。
2. `source_main_image_url`：核价采集到的 Temu SKC 主图，直接作为 `<img>` 地址展示，并设置 `referrerPolicy="no-referrer"`。
3. 两者都不存在时显示“无图”与上传按钮。

用户上传图片后，页面立即本地预览；保存成功后，该本地图覆盖外链核价图。上传操作不删除 `source_main_image_url`，从而保留可追溯的核价来源。

### 异常处理

- 外链图片加载失败时，单元格回退为“无图/上传”，不影响产品库查询或核价同步。
- 主图 URL 为空时保持旧行为。
- 同步异常继续保持当前的“核价关联操作成功、产品库回填尽力而为”语义。

## 验收与测试

- 核价同步创建或更新产品库记录时，返回 `source_main_image_url`。
- 已存在、无 `image_path` 的核价产品在启动回填后有 `source_main_image_url`。
- 已上传本地图的核价产品，回填后 `image_path` 不变且前端优先展示本地图。
- 只有核价 URL 的产品，前端直接展示外链主图。
- TypeScript 构建和相关 Python 测试通过。
