# Bilibili 新手卖家推广视频制作计划

> **For agentic workers:** 本文用于录屏、剪辑、配音与发布协作；每个镜头完成后勾选。

**Goal:** 制作一条 80–100 秒、无人物出镜的 Bilibili 口播视频，引导跨境电商新手下载试用 MainPG。

**Structure:** 用“新手第一单”串联选品、处理、核价利润和导出四步。全片以真实软件录屏为证据，商品素材和动态图形只用于强化重点。

**Tech Stack:** 屏幕录制软件、剪映/PR、AI 或真人中文配音、MainPG 测试账号与脱敏演示商品。

## Global Constraints

- 成片时长 80–100 秒；建议 92 秒。
- 无真人出镜；不展示真实客户信息、订单、密钥、余额、Cookie 或平台后台敏感数据。
- 不使用“躺赚”“保证爆单”“全自动赚钱”等承诺性表述。
- 下载入口使用发布时可核验的官网链接、置顶评论或 B 站组件链接。

## 交付素材清单

### 必录屏幕

- [ ] 登录后的工作台首页：展示四个业务分组，不出现真实用户名或钱包信息。
- [ ] 「产品处理 → 采集」：关键词输入、平台和站点选择、候选商品加载、勾选入池。
- [ ] 「AI处理」：草稿池、商品任务、处理进度或预览结果。
- [ ] 「POD定制 → 全定制」：模板或批次创建、图片/标题结果、导出入口。
- [ ] 「POD定制 → 半定制」：提示词或花色图批次、打包下载入口（有演示数据时录制）。
- [ ] 「核价及货源 → 核价/货源匹配」：报价或候选货源界面。
- [ ] 「利润活动」：利润预览或筛选结果。
- [ ] 预检完成后的导出页面：仅展示文件类型、导出按钮或成功状态。
- [ ] 软件登录页或官网首屏：作为结尾下载画面。

### 辅助素材

- [ ] 3 张已获使用授权的无品牌家居/收纳类商品图，统一裁成 1:1。
- [ ] 一张“浏览器标签页堆叠”的抽象素材，或用剪辑软件绘制 6 个浏览器窗口。
- [ ] 鼠标点击、加载、勾选、完成音效各 1 个；轻快电子 BGM 1 首，确保可商用。
- [ ] MainPG Logo、软件名称和下载二维码。二维码内容为 `https://workbench.haocoming.top/`，发布前需重新扫码验证可用。

## 分镜与文案

### 镜头 1：开场钩子（0:00–0:05）

**画面**：快速切换浏览器搜索、表格、计算器、商品页的四个抽象窗口；最后停在一句大字“第一单，到底从哪开始？”

**口播**：

“刚开始做跨境电商，最难的往往不是努力，而是不知道第一步该做什么。”

**屏幕字幕**：`选品？资料？核价？利润？`

**剪辑**：前四秒每 0.6 秒切一张，最后一秒停顿并让 BGM 落点。

### 镜头 2：痛点放大（0:05–0:11）

**画面**：左侧是多窗口和零散表格，右侧依次弹出“找商品”“整理图片”“写文案”“算利润”四张任务卡；任务卡堆满画面后压缩消失。

**口播**：

“找商品、整理图片、写资料、核价格、算利润，来回切工具，刚入门很容易卡在半路。”

**屏幕字幕**：`工具很多，流程却是断的。`

**剪辑**：不使用真实平台账号页面；用脱敏录屏或图形复刻表达杂乱。

### 镜头 3：产品登场（0:11–0:17）

**画面**：窗口收拢成 MainPG 工作台首页，镜头缓慢推进左侧导航；依次高亮“产品处理”“POD定制”“核价及货源”。

**口播**：

“MainPG 把新手最常用的动作，放进了一个本地工作台。今天就拿一个商品，跑完第一条流程。”

**屏幕字幕**：`从一个商品开始，跑通你的第一条流程`

**剪辑**：Logo 和产品名称在第 14 秒出现一次即可，避免持续占屏。

### 镜头 4：第一步，采集（0:17–0:27）

**画面**：录制“采集”页面。输入示例关键词“收纳篮”，选择平台与站点，点击开始采集；候选商品卡片出现，框选其中一张商品卡并勾选。

**口播**：

“第一步，先从关键词或参考图开始采集。看到合适的候选，勾选后就能进入草稿池，不用先在好几个表格里搬来搬去。”

**屏幕字幕**：`关键词 / 参考图 → 候选商品 → 草稿池`

**素材要求**：使用演示关键词和脱敏商品；候选卡中不得露出商家账号、采购价格或接口密钥。

### 镜头 5：第二步，AI 处理（0:27–0:37）

**画面**：切到“AI处理”草稿池，选中刚才的商品；展示任务设置、进度状态和一组预览结果。用前后分屏对比“原始资料”与“处理后的标题/图片预览”。

**口播**：

“第二步，商品资料在草稿池里统一处理。图片、标题、卖点这些上架前最耗时间的准备工作，可以按任务推进，再回来看预览。”

**屏幕字幕**：`草稿池统一管理 · 任务进度可见`

**剪辑**：任务进度采用已录好的成功样例；不承诺生成时间，不展示模型密钥。

### 镜头 6：POD 定制（0:37–0:49）

**画面**：切换到“POD定制 → 全定制”。展示模板/批次列表、已生成的图片与标题结果，以及导出入口；有半定制演示批次时，用 2 秒展示“半定制”的花色图批次和下载入口。

**口播**：

“如果你做的是 POD，这里也能把模板、批次、图片和标题放进同一条定制流程。全定制做成品图和资料，半定制按提示词生成花色图，再按批次整理导出。”

**屏幕字幕**：`POD 全定制 · 半定制 · 批次导出`

**剪辑**：先用模板图或批次卡建立理解，再快速切三至四张已生成成品图；不展示未授权模板、顾客个性化信息或真实订单。

### 镜头 7：尺寸与预检（0:49–0:56）

**画面**：展示尺寸画布或预检页面，镜头放大尺寸标注和图片清单，再切到“预检通过”的状态标记。

**口播**：

“需要尺寸图和上架前检查的，也能在流程里继续完成。先把资料补齐，再决定要不要往下一步走。”

**屏幕字幕**：`尺寸图 · 图片清单 · 上架前预检`

### 镜头 8：第三步，核价与找货源（0:56–1:06）

**画面**：展示“核价/货源匹配”页面：一个报价条目、一组候选货源卡和人工保留操作。用高亮框强调“人工确认”。

**口播**：

“第三步，别只看商品好不好看。把报价和候选货源放在一起对照，最后由你自己保留需要的结果。”

**屏幕字幕**：`报价核验 · 货源匹配 · 人工确认`

**剪辑**：不要展示“最低价”“稳赚”等导向结论；重点放在核验与决策支持。

### 镜头 9：第四步，利润活动（1:06–1:15）

**画面**：切至“利润活动”，展示利润预览数字区域与筛选结果；用动画从“成本、售价、费用”汇聚为“利润判断”。

**口播**：

“核价之后，再把成本、售价和费用放进利润判断。不是凭感觉选品，而是让每一步都有数据可以回看。”

**屏幕字幕**：`成本 + 售价 + 费用 → 利润判断`

**素材要求**：使用虚构或脱敏的演示数字，屏幕角标标明“示例数据”。

### 镜头 10：导出结果（1:15–1:23）

**画面**：回到预检完成页，点击导出；出现“已生成导出文件”状态，再展示文件夹中的脱敏示例文件名。最后回到完整流程条。

**口播**：

“资料确认后，导出需要的商品文件。你不必一开始就把所有功能学会，先把一条流程跑通就够了。”

**屏幕字幕**：`采集 → 处理 → 核价 → 利润 → 导出`

### 镜头 11：收束价值（1:23–1:30）

**画面**：前面五个模块的关键画面各缩成一张卡，按流程连成一条横线；商品主图在流程末端出现。

**口播**：

“对新手来说，最有价值的不是多一个功能，而是少一点不知道下一步该点哪里的焦虑。”

**屏幕字幕**：`把第一条流程跑通，再开始迭代。`

### 镜头 12：行动号召（1:30–1:38）

**画面**：软件登录页或官网首屏，右侧放下载二维码与“置顶评论 / 简介链接”提示。鼠标停在下载按钮上，不必真的点击。

**口播**：

“想从第一件商品开始试一试，点击简介里的下载链接，安装 MainPG，自己跑一遍流程。”

**屏幕字幕**：`下载试用 MainPG`  
`链接见简介 / 置顶评论`

**发布前检查**：将口播中的“简介里的下载链接”与实际发布位置一致；若使用 B 站组件，改为“点击下方链接”。
