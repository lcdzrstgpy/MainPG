## 一、爆款复刻（replica）主流程落地

- **识图主流程**：A 原素材图（`pattern_source`）+ B 目标产品白底图（`target_product`）→ 事实分析 / 能力匹配 / 确定性规则 / 构图模板 → 四段式 Prompt 编译 → 冻结并持久化 `ReplicaPlan`，失败可重试、可恢复
- **生成策略**：`grid`（一次 2×2）与 `independent_panels`（4 个单面板 × 每面板 2 次尝试）；单面板失败只重试该面板，不拖垮整款
- **计划输入指纹缓存**（迁移 `022_replica_plan_fingerprint`）：决定 `ReplicaPlan` 的全部输入（事实 / 能力 / 规则 / 展示偏好 / 构图模板 / 生成策略 / 版本号）哈希成指纹——同输入**直接复用已冻结计划，不再重复调用豆包**；同批次同款只调一次；跨用户、跨工作区绝不复用
- **评审缺口修复**：
  - 带 `analysis_id` 的款若缺冻结计划 → worker **硬失败**，不再静默回退旧 Prompt / grid
  - A 原素材低置信度必须用户确认（`source_confirmed`）才能提交
  - `image_model_version` 随计划冻结，供事后归因
  - `independent_panels` 写入调用级 Prompt 快照，审计可追溯
- **「生活场景」偏好真正驱动背景**：原来该开关无人读取，生成图没有背景；现在由它决定是否产出生活场景背景与硬约束
- **构图模板按模块分池**（迁移 `021_composition_scope`，`scope = full | replica`）：复刻不再借用全定制的产品化模板；显式把全定制模板挂到复刻批次返回 409；无复刻模板时回退系统默认机位

## 四、POD 标题生成风控

- **禁用词表大幅扩充**（约 190 条，整词匹配），按类分组维护：
  - 平台名、品牌 / IP、绝对化与促销、医疗功效、儿童母婴、联系方式
  - 暗黑邪典（gothic / pentagram / occult / skull / dagger / raven / spider / thorn…）
  - 武器暴力、成瘾物、成人向、赌博、仿品侵权（replica / counterfeit / knockoff…）、仇恨与政治敏感
  - 维护约定：**不收录 `apple` / `blade` / `pill` / `nude` 这类既是常见词又是风险信号的词**，避免误杀合法标题
- **提示词新增规则**：中性改写（如用 `black bird motifs` 代替 `raven`、`ornate decorative patterns` 代替 `gothic`）+ 只允许半角 ASCII 标点
- **全角 / 弯体标点归一为 ASCII**（标题 / 英文标题 / 描述三处）：模型写出中文全角横杠、弯引号时不再被判「非英文字符」而整款失败
- 「标题/描述限制」字段填写前弹出**红字强提示**（「依旧填写」/「取消」，取消即回退本次输入），与字段本身的高风险属性一致
