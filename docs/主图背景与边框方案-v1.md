# 主图背景与边框方案 v1.1（三条路径）

> 问题：四个模板的主图都是纯白底，客户反馈单调。
> 修订（v1.1）：**平台没有白底硬性要求**，此前把“主图必须纯白”写死在提示词里是错的。
> 现在主图默认走**场景背景**，白底降为一个可选档；代码里写死的纯白豁免已参数化为 `main_background`。

---

## 一、背景政策

| 档位 | 说明 | 默认 |
|---|---|---|
| `scene` | 主图也带真实台面 + 背景 + 景深，按品类取场景与零件 | ✅ |
| `white` | 主图纯白无缝、无道具无场景（旧行为） | 可选 |

- 批次设置里新增「主图背景」下拉，默认 `scene`；老任务/老客户端不传时按 `scene` 处理。
- 白底不再是“合规红线”，而是“某客户/某平台喜欢干净底”时的可选项。
- 边框（frame）现在主图也能用，但仍受下面两条约束：不与主体、道具、分格线冲突；不遮挡产品关键结构。

---

## 二、三条路径怎么分工

| 路径 | 可控性 | 变化度 | 素材成本 | 一致性 | 适合放哪 | 实现方式 |
|---|---|---|---|---|---|---|
| ① 纯提示词控制背景 | 中（结构可控，细节随机） | 高 | 0 | 弱（每张都不同） | 主图、轮播、详情、社媒图 | 文本生成背景 |
| ② 系统基础模板 | 高 | 中（模板库内轮换） | 20-40 张素材 | 强（成套） | 主图、轮播，可锁定为店铺风格 | 合成或参考图 |
| ③ 自定义上传模板 | 最高 | 低（客户自己定） | 客户自备 | 最强（品牌统一） | 店铺统一视觉、私域/独立站 | 合成（抠图 + 底图 + 光影） |

三者不互斥：店铺级策略 + 每批可覆盖。默认 `auto`（系统在 ①② 之间轮换），客户可锁 ②（选一个喜欢的模板）或切 ③（上传自己的背景）。

**为什么不提前批量生成固定背景**：预生成会把所有店铺钉死在少数几张图上，同质化且无法跟随季节/品类变化；所以背景资产只在“系统模板”这一层提前做，但**不做死**，永远与提示词、自定义模板并存。

## 三、路径 ①：纯提示词控制背景

### 3.1 结构

现有 `Scene` 已包含「台面 + 背景 + 景深」。走路径 ① 时只替换**背景部分**，台面与景深保留：

```text
Scene: {台面}, {背景板}, {景深}; Set: ...;
```

### 3.2 背景片段库（每段 ≤8 词，按品类选）

| id | 片段 | 适配 |
|---|---|---|
| `bd_paper_sweep` | pale gray paper sweep, soft floor transition | 通用、办公、数码 |
| `bd_plaster_wall` | warm plaster wall with soft window gradient | 家居、宠物 |
| `bd_oak_edge` | light oak table edge against off-white wall | 家居、工具 |
| `bd_linen_drape` | draped ivory linen backdrop, gentle folds | 服装、美妆 |
| `bd_terrazzo` | warm terrazzo surface, matte finish | 美妆、文具 |
| `bd_frosted_panel` | frosted glass panel with diffused backlight | 数码、个护 |
| `bd_metal_strip` | brushed metal strip along the top edge | 工具、汽车 |
| `bd_gradient_studio` | clean studio gradient, seamless top-to-bottom | 通用兜底 |

### 3.3 边框片段（主图与轮播都可用）

| id | 片段 | 说明 |
|---|---|---|
| `fr_thin_oak` | thin oak frame along the image edge | 轻边框，不压迫主体 |
| `fr_matted_paper` | matted paper border, 6% margin | 画框式留白 |
| `fr_soft_vignette` | soft vignette at the corners | 最不抢戏，适合所有品类 |
| `fr_gallery_wall` | gallery wall shadow behind the frame | 家居/装饰类 |

负面词固定追加：`no text, no logo, no watermark`；边框不得压住产品或跨过分格线。

### 3.4 一致性控制

- 同一批 4 格用**同一个背景片段 + 同一色温**，避免每格背景各异。
- 路径 ① 的随机性来自模型，不来自提示词；需要稳定时切路径 ②/③。

## 四、路径 ②：系统基础模板库

### 4.1 模板分类（先做 20 张，覆盖 12 个品类）

| 风格族 | 数量 | 示例 | 默认可用面板 |
|---|---|---|---|
| 纯色/渐变 | 5 | 暖白、雾灰、燕麦、浅杏、冷灰 | 1-4 |
| 纸感/石膏 | 3 | 米白纸、暖灰石膏、粗纹纸 | 1-4 |
| 木石台面 | 5 | 浅橡木、胡桃木、暖灰石、水磨石、白大理石 | 1-4 |
| 布艺 | 3 | 亚麻、棉麻、绒面 | 1-4 |
| 几何/建筑 | 2 | 拱形墙洞、阶梯台 | 2-4 |
| 节庆（仅 ornate） | 2 | 松枝暖灯、礼盒丝绒 | 2-4 |

### 4.2 模板元数据

已落地在 `background_presets.py`（后端）与 `backgroundTemplates.ts`（前端），20 张底板在 `web-frontend/public/assets/backgrounds/*.svg`。

```ts
type BackgroundTemplate = {
  id: string;                 // bd_oak_light_01
  name: string;               // 浅橡木台面
  source: 'system' | 'user';
  styleFamily: 'solid' | 'paper' | 'wood_stone' | 'fabric' | 'geo' | 'festive';
  imageUrl: string;           // 3000x3000 sRGB
  thumbUrl: string;           // 480x480
  aspect: '1:1' | '4:5';
  safeArea: { x: number; y: number; w: number; h: number }; // 主体区，禁止高频纹理
  categories: string[];       // 适配品类 id，空=全品类
  colorFamily: string;        // warm / cool / neutral / festive
  usableForMain: boolean;     // 系统模板默认 true；纯白模板单独一条
  status: 'active' | 'hidden';
};
```

> 20 张已换成豆包生成的实拍质感底板（`web-frontend/public/assets/backgrounds/*.jpg`，1200×1200）。
> 生成方式：豆包按 `docs/豆包背景底板提示词-四宫格-v1.txt` 出 2×2 四宫格 →
> `python devtools/prepare_backgrounds.py` 自动裁掉底部「豆包AI生成」水印、切四象限、统一 1200×1200。
> 换图时同 id 覆盖即可，选择与轮换逻辑不变。

### 4.3 去同质化（关键）

- **批次内成套**：4 格复用同一模板，保证一张商品图是一套。
- **跨批次轮换**：`bucket = hash(shop_id + batch_id) % 候选数`，候选先按品类白名单 + 色系过滤。
- **店铺最近 N 张去重**：记录 `background_usage(shop_id, template_id, used_at)`，同店铺最近 20 张出现过的模板降权，重复率目标 <30%。
- **客户锁定例外**：店铺设置里选「固定模板」时不再轮换，但仍按品类白名单校验（花盆配水磨石合理，配节庆丝绒就怪）。

### 4.4 店铺级策略

```ts
type ShopBackgroundPolicy = {
  shopId: string;
  mode: 'auto' | 'fixed' | 'prompt_only' | 'custom_only';
  templateId?: string;        // mode=fixed 时必填
  mainBackground: 'scene' | 'white';
  updatedAt: string;
};
```

## 五、路径 ③：自定义上传模板

### 5.1 上传规范

- 尺寸 ≥ 2000×2000（1:1）或 ≥ 2000×2500（4:5），sRGB，JPG/PNG，≤15MB。
- 禁止：文字、水印、logo、人物、明显品牌物、过曝/死黑。
- 主体区（中心 60%）不能有强对比高频纹理，否则合成后主体被“吃掉”。

### 5.2 处理管线（后端一次做完，落 3 个文件）

1. 剥 EXIF、转 sRGB、按安全区裁到 1:1/4:5；
2. 白平衡与曝光归一（防止客户给的图偏黄/偏暗）；
3. 生成主体区轻微虚化/降饱和蒙版（可选，可关）；
4. 生成接触阴影层（椭圆软阴影，强度按模板明度自动给）；
5. 输出：`original.jpg`、`composite_base.jpg`、`thumb.jpg`。

### 5.3 使用方式

- 优先**直接合成**：主体抠图（现成 rembg）→ 贴到模板安全区 → 叠接触阴影 → 边缘羽化 + 色温匹配。
- 不上模型重绘，成本几乎为 0，主体 100% 保真。
- 客户要求“更自然”时，再走一次轻量 image-to-image（可选付费）。

### 5.4 共享与合规

- 模板归属个人，可勾选「共享给团队」；团队管理员可下架。
- 客户上传即确认拥有使用权；含文字/logo 的模板不允许用于主图。

## 六、出图方式对比

| 方式 | 说明 | 成本 | 主体保真 | 适用 |
|---|---|---|---|---|
| A 纯文生图 | 提示词描述背景，模型一次出图 | 1 次调用 | 中（可能微改主体） | 路径 ① |
| B 参考图生图 | 模板图作为 style/scene 参考 | 1 次调用 | 中 | 路径 ②，想要“氛围迁移” |
| C 合成 | 抠图 + 底图 + 阴影，不重绘 | 0 次生图 | 最高 | 路径 ②③，主推 |

**建议**：系统模板与自定义模板都走 C；纯提示词走 A；B 只作为增值选项。

## 七、主图质感增强（两条档位都要做）

| 手段 | 具体做法 | 词/参数 |
|---|---|---|
| 主体占位 | 主体占画面 58-72%，四周留呼吸空间 | frame 卡调整 |
| 接触阴影 | 主体正下方 2-3% 高度的极淡投影 | `soft contact shadow` |
| 边缘柔光 | 轮廓一圈柔和边光，避免“贴纸感” | `rim light` |
| 背景层次 | `scene` 档：台面 + 背景 + 景深三段；`white` 档：底部 8% 区域 2-3% 灰渐变 | `very subtle bottom gradient` |
| 质检 | 主体占比、边缘融合、同批背景一致性 | 出图后抽检 |

## 十、验收指标

1. 主图背景与批次设置一致（`scene` 有背景、`white` 纯白），抽检一致率 ≥98%。
2. 同店铺最近 20 张图的背景重复率 **<30%**。
3. 人工审图通过率提升 **≥10%**（对比纯白底基线）。
4. 合成路径不增加生图调用次数（成本持平），端到端耗时增加 **≤300ms/张**。
5. 客户主动锁定模板的比例、自定义上传使用率作为迭代依据。

## 十二、风险清单

| 风险 | 应对 |
|---|---|
| 某些平台确有白底要求 | 批次/店铺可切 `white`，不写死 |
| 背景抢戏、主体不突出 | 主体占比 58-72%、道具从属、同批同背景 |
| 合成后主体像“贴纸” | 接触阴影 + 边缘羽化 + 色温匹配三件套 |
| 模板同质化 | 批次哈希 + 店铺最近 N 张去重 + 品类白名单 |
| 客户上传违规内容 | 上传校验（文字/logo/人物）+ 团队可下架 + 仅本人/团队可见 |
| 素材版权 | 系统模板自建或 CC0；客户上传需勾选授权 |
