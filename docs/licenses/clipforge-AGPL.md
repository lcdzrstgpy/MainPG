# ClipForge attribution and source availability

MainPG vendors a direct source copy of ClipForge in `integrations/clipforge`,
based on `47f7f900d5357be7ad60e24b2ded9f199a510a61` from
`https://github.com/xixihhhh/clipforge`.

ClipForge is licensed under AGPL-3.0-only. Distributions of MainPG that include
this component must retain its copyright and licence notices. If users interact
with a modified ClipForge service over a network, provide them the corresponding
source for that running ClipForge component, including the Suchuang adapter and
any other modifications.
