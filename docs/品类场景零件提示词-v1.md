# 品类场景 + 零件提示词 v1（结构化 · 富集版）

> 用途：AI 出图时按识别出的品类，替换原 Prompt 里的 `Scene` 片段。
> 规则：`Scene` 只写台面 / 背景 / 景深，**不写光照**（光由 L2 光影卡片给）；`Set` 的件数跟着「场景风格」走，最花哨的一档封顶 **6 件**。
> 格式：`Scene: xxx; Set: a, b, c;`（`Set` 为空时整段省略）
> 数据落地：`web-frontend/src/modules/product_processing/data/scenePropPresets.ts`
> 分类 id 与 `category_image_presets.py`、`imageCardOptions.ts` 一致。

## 一、零件数量按场景风格分配

`sceneStyle` 是批次里已有的设置（smart / minimal / lifestyle / ornate），直接复用它当零件密度档位：

| sceneStyle | 含义 | 零件上限 | 品类段词预算 | 适用 |
|---|---|---|---|---|
| `minimal` | 极简 | 1 件 | ≤ 20 词 | 主图、白底、标品 |
| `lifestyle` | 生活（默认） | 3 件 | ≤ 28 词 | 常规轮播、详情 |
| `smart` | 智能混合 | 4 件 | ≤ 32 词 | 按批次在极简/生活/花哨之间轮换 |
| `ornate` | 花哨 | **6 件（封顶）** | ≤ 40 词 | 节庆、礼品、潮玩，只用于生活场景格与平铺格 |

- 6 件是**硬上限**：再多会挤占主体注意力，且整条提示词超预算。
- 花哨档的 6 件必须来自 **6 个不同材质族**（木/陶瓷/石/布/纸/金属/植物/玻璃/软木/混凝土/皮革/藤编），同族只留一件。
- 主图格与微距格永远不使用零件，无论什么风格。

## 二、冲突替换规则

| # | 触发条件 | 处理 |
|---|---|---|
| 1 | 主体为木制品 | 移除 `light oak block / walnut cutting board / oak hanger`，替换为 `warm gray stone slab` 或 `kraft paper sheet` |
| 2 | 主体白色 / 陶瓷 | 移除 `white ceramic dish / acrylic tray / matte black ceramic cup / terracotta pot`，替换为 `warm gray stone slab` 或 `brass clip` |
| 3 | 主体绿色 / 植物 | 移除 `eucalyptus sprig`，替换为 `kraft paper sheet` |
| 4 | 主体纺织布料 | 移除 `washed linen cloth`，替换为 `warm gray stone slab` |
| 5 | 主体与零件同色系 | **直接删除该零件，不做替换** |
| 6 | 商品本体即是某零件（瑜伽垫、花盆、笔记本、水杯等） | 删除该零件，由候补件补位 |

执行顺序：6 → 1 → 2 → 3 → 4 → 5 → 同材质去重 → 截断到风格上限。
替换候选被占用时顺延下一个候选；候选全部占用则删件；最多替换 1 次，不连锁替换。
删件后**用候选池后面的件补位**，保证生活档仍是 3 件、花哨档尽量到 6 件。

两条防误判补充：

- **颜色由中文词推断**：主体识别没给结构化颜色时，从标题/材质里取「白/米白/灰/黑/绿/木色/沙色/金/陶土/透明/牛皮纸」→ 对应颜色族，再执行规则 5。
- **仿品不按真材质处理**：标题含「仿 / 假 / 贴皮 / faux / imitation / looks like」时跳过规则 1-4（例如「仿木纹塑料收纳盒」不会把木道具换掉），只保留规则 5、6 与去重。

## 五、拼装逻辑与预算

```text
scene = SCENE_PRESETS[category].main          # 撞色/不符时取 alt
limit = {minimal:1, lifestyle:3, smart:4, ornate:6}[sceneStyle]
props = resolvePropConflicts(category, subject, {style: sceneStyle}).slice(0, limit)
line  = f"Scene: {scene}; Set: {', '.join(props)};"   # props 为空时省略 Set
```

- 品类段预算：极简 ≤20 词、生活 ≤28 词、智能 ≤32 词、花哨 ≤40 词。
- **每个零件带定格摆位**（`PROP_PLACEMENTS`）：第 1 件 upper-left、第 2 件 lower-right、第 3 件 upper-right、第 4 件 along-left、第 5 件 along-right、第 6 件 upper-center。摆位用上下左右而非前后，俯拍和 45° 都成立，一件只多 1 个词。
- 零件按「垫高/结构 → 承载/质感 → 点缀/颜色 → 补充材质」的顺序排，模型对前半段权重更高。
- 不换行、不用 `{}`、不写中文，直接替换现有品类提示词的 `Scene:` 段，`Focus / Show / Avoid` 保留。
- 接入前用 `validateScenePropLine(line, style)` 自检，返回 `{ words, budget, overBudget }`，超预算就降一档。`SCENE_PROMPT_BUDGET` 里就是上面四个数字。
- **素材齐备后可切贴图模式**：`PROP_ASSETS` 里 6 件都有图时，`Set:` 自动缩成 `supplied prop cutouts`（4 词），模型改用参考图而不是文字想象，提示词长度还能再降 25 词左右。

### 花哨档示例（6 件，35 词）

```text
Scene: warm oak countertop, warm gray plaster wall, shallow depth; Set: upper-left walnut cutting board, lower-right white ceramic dish, upper-right eucalyptus sprig, along-left warm gray stone slab, along-right kraft paper sheet, upper-center rattan storage box;
```

### 素材就绪后的贴图模式（4 词）

```text
Scene: warm oak countertop, warm gray plaster wall, shallow depth; Set: supplied prop cutouts;
```

## 六、四格用法

| 格位 | 卡片 | 背景 | 零件（`minimal` / `lifestyle` / `smart` / `ornate`） |
|---|---|---|---|
| 1 主图 | `frame_hero` | 跟批次「主图背景」：`scene` 有背景 / `white` 纯白 | 0 / 0 / 0 / 0 |
| 2 细节 | `frame_macro` | 随模板 | 0 / 0 / 0 / 0 |
| 3 生活场景 | `frame_environment` | 随模板 | 1 / 3 / 3 / 6 |
| 4 平铺 | `frame_flatlay` | 随模板 | 1 / 3 / 6 / 6 |

这张表就是代码里的 `GRID_PANEL_STYLES`：`null` 表示该格不出零件。
`smart` 档靠它实现「生活 + 花哨」混合——第 3 格克制、第 4 格铺满，四格不雷同；`ornate` 两格都满，适合节庆/礼品/潮玩。
主图**只用背景、不放零件**：主图要的是产品第一眼，加道具会分散注意力；背景由 `main_background` 档位决定（默认 `scene`）。

## 八、质检清单

1. 零件件数与风格档位一致：极简 1 / 生活 3 / 智能 4 / 花哨 ≤6。
2. 花哨档 6 件是否来自 6 个不同材质族，无同族重复。
3. `Scene` ≤12 词且不含光位；`validateScenePropLine` 不超预算。
4. 删除与替换规则执行后仍能补满到该档位（候补件够用）。
5. 商品本体对应的零件已删除（瑜伽垫、花盆、笔记本、碗、水杯等）。
6. 产品配件（杯盖、背带、收纳袋）不得写进 `Set`。
7. 最终整条 prompt 无换行、无 `{}`、无中文，总长 ≤85 词。
8. 「仿 / 假 / 贴皮」类主体没有触发真材质换件；白色/灰色主体没有和同色零件糊在一起。
9. 每个零件都带摆位词，且摆位不重复（6 件时刚好用满 upper-left / lower-right / upper-right / along-left / along-right / upper-center）。

## 九、常见翻车与对策

| 现象 | 根因 | 对策（已落在提示词/代码里） |
|---|---|---|
| 主体悬空、像贴上去的 | 只写了台面，没有落地关系 | `Scene` 里保留台面词（countertop / desk / floor），并靠 L2 卡片的 contact shadow 落地 |
| 道具比主体还抢眼 | 零件太多、尺寸无约束 | 档位上限（生活 3、花哨 6）+ wrapper 的「props subordinate」；主图/微距 0 件 |
| 主体和道具同色糊成一片 | 没有颜色判断 | `detectSubjectColor` 识别白/灰/黑/绿等，命中即删件并从池里换一件不同色的 |
| 明明是仿木纹塑料，木道具却被删 | 把「仿」当真材质 | `FAUX_MATERIAL_HINTS` 命中时跳过材质替换 |
| 花哨档 6 件里有 2 个石头 | 同材质堆叠 | `PROP_MATERIAL_FAMILY` 去重，同族只留一件 |
| 同一零件两种写法导致重复 | `stone slab` / `warm gray stone slab` 并存 | 已统一为 `warm gray stone slab`，旧写法不再入库 |
| 四格背景雷同 | 全用同一档 | `GRID_PANEL_STYLES`：智能档第 3 格生活、第 4 格花哨 |
| 提示词越写越长 | 每格都堆满零件 | 词预算 + `validateScenePropLine` 自检，超了降档 |
| 品类判错导致场景全错 | 分类只按标题 | 前端保留品类下拉可覆盖；未命中走 `general` 中性场景，不硬猜 |
| 6 件道具全挤在主体四周 | 只给了名字没给位置 | `PROP_PLACEMENTS` 按序号固定摆位，一件只多 1 个词 |
| 换了零件图后提示词还是长 | 仍在逐个描述零件 | `PROP_ASSETS` 填满后自动切 `supplied prop cutouts`，提示词再省约 25 词 |
