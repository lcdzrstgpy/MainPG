# ClipForge AI 视频模块：功能入口与流程盘点

> 盘点日期：2026-09-22  
> 范围：MainPG 内置的 `integrations/clipforge` 模块；不包含 MainPG 其他业务模块。  
> 目的：解释“为什么同一个视频功能有多套入口、同一次出片会走不同链路”，并给出合并优先级。本文是现状审计，不代表已经完成整改。

## 结论先行

当前模块的能力并不缺，问题在于它同时保留了 **快速工作台、导演式新建项目、爆款复刻、话题成片、批量出片** 等多条创建路径。它们都能创建“项目”，但携带的创作参数不同、默认值不同、后续是否自动执行也不同。

最影响成片质量和用户判断的三件事：

1. 首页 `/start` 默认选择“免费快剪”，而它的自动流水线只做“脚本质检 → 免费素材填充 → FFmpeg 合成”。这不是豆包生视频链路，最终天然更像带平移/缩放的图片拼接。
2. 高级项目页 `/project/new` 才有完整的受众、平台、视频模式、脚本风格、模板与角色配置；首页只提供 4 个简化风格预设。因此用户会感觉“明明找得到风格，但主页上没地方设置”。
3. “智能推荐 / auto”在没有足够历史投放数据时会被后端标准化为 `pain_point`（痛点种草）。这就是脚本风格频繁落到“痛点种草”的直接原因，不是模型随机偏好。

此外，代码里仍残留 Atlas Cloud 的一键配置、文案、设置项和兼容逻辑；这与当前只使用 **火山/豆包 + 速创** 的产品约束冲突，容易把用户带去错误的 Key、模型和计费路径。

## 1. 入口全景

| 入口 | 对用户的含义 | 当前实际链路 | 是否与其他入口重叠 | 风险等级 |
|---|---|---|---|---|
| `/start` 工作台 | 上传商品图、商品链接或一句话主题，快速出片 | 默认“免费快剪”；创建项目后带 `?auto=1` 自动执行免费流水线 | 与“新建项目”高度重叠 | P0 |
| `/project/new` 新建带货项目 | 完整填写商品、受众、平台、时长、模式、脚本风格、模板、角色 | 只生成脚本并进入脚本页，之后由用户选择素材/视频/导出 | 与工作台同为项目创建 | P0 |
| `/project/topic` 一句话主题成片 | 面向非商品主题的脚本生成 | 独立调用 `/api/topic/script` 创建 topic 项目 | 与工作台中的“一句话成片”重复 | P1 |
| `/project/clone` 爆款复刻 | 按趋势/示例复刻结构 | 独立建项目、独立分镜/复刻配置 | 应保留为“创作方式”，不应伪装成另一套主流程 | P1 |
| `/batch` 批量出片 | 多商品批量生成 | 内部又拥有脚本、质检、自动合成逻辑 | 与单项目自动流水线重复部分能力 | P1 |
| `/products` 商品素材库 | 保存/导入商品信息与素材 | 能转去创建和批量 | 入口合理，但当前创建跳转目标不唯一 | P2 |
| `/presenters` 主播素材库 | 保存人物/声音资料 | 在新建项目和部分首页预设中被分别读取 | 角色选择入口分散 | P2 |
| `/media-lab` 媒体解构 | 分析参考媒体 | 单独工具入口 | 与爆款复刻相邻但没有明确衔接 | P2 |
| `/projects` 我的项目 | 恢复项目、查看成片 | 同时提供“去工作台”和“新建项目”两个创建入口 | 放大两条主入口的选择困难 | P1 |

### 导航层面的矛盾

侧栏的设计意图是：小白模式仅显示“工作台”，导演模式再显示“新建项目、媒体解构、批量出片”。但在项目列表、导出页、示例页等位置仍然出现“新建项目”的直链，所以实际并没有形成一个明确的主入口。

也就是说，产品试图用“小白/导演模式”解决复杂度，但底层仍维护了两套创建表单和两套跳转语义。

## 2. 两条主创建链路的字段差异

### A. 首页工作台 `/start`

可输入：商品图片、商品链接、一个话题、商品名称、卖点。

可见创作控制：

- 生成模式：`免费快剪` / `AI 生成成片`；默认值为 **免费快剪**。
- AI 模式下只有 4 个预设：自动、主播口播、剧情、图文混剪。
- 主播/剧情时可选角色。
- 可选择制作档位，但它主要影响分辨率、速度、成本，不等于创作主题。

它向脚本接口发送的核心字段只有：商品名、商品描述、固定 `other` 品类、固定 30 秒、预设映射出的 `styleType` 和 `videoMode`、商品图、LLM 配置、可选角色。

它**不会**提交：目标人群、投放平台、价格带、使用场景/利益点、完整模板、明确的自定义创作要求。用户对“人物处境、场景、语言、语气、受众”的要求在这里没有稳定入口。

### B. 导演式新建项目 `/project/new`

可输入/选择：

- 商品图片、商品链接、商品名称、品类、卖点；
- 时长（15/30/60 秒）；
- 视频模式（产品特写、图文混剪、场景演示、真人出镜）；
- 脚本风格（情景短剧、反转、街采、故事、开箱、物品拟人、对比测评、达人口播、痛点种草、场景安利、智能推荐等）；
- 价格带、目标受众、投放平台、使用优势；
- 脚本模板、广告模板、角色/主播。

它会将上述绝大多数字段传给 `/api/llm/script`，因此确实是当前唯一接近“创作简报”的页面。

### 造成的问题

两页不仅是 UI 简繁差异，**它们发送的请求体也不同**。相同商品从不同页面创建，脚本的内容、模式和后续出片路径会不同；用户看不到这种分叉，也无法在项目详情中追溯“本次到底缺了哪些创作条件”。

## 3. 当前实际出片链路

### 3.1 免费快剪：默认自动链路

工作台默认模式为 `free`。创建成功后，脚本页收到 `?auto=1`，会自动启动服务端流水线：

```text
脚本（可选质检改写）
  → 免费素材匹配 / stock-fill（失败不阻断）
  → FFmpeg 合成 + 免费 Edge TTS
  → 导出页
```

这个流水线定义为 `judge → stock_fill → compose`，没有“生成每个镜头的视频”的阶段。因此即便文案中出现“AI 正在出片”，它也可能只是用静态商品图/素材图进行 Ken Burns、平移、缩放等本地运镜后合成。

它适合明确标注为“免费草稿 / 素材快剪”，不应被默认为“AI 视频生成”。

### 3.2 导演可控链路：逐镜素材与动态生成

在项目的“素材”页，用户可以：

- 生成或上传每镜画面；
- 为镜头选运镜、修改镜头提示词；
- 可选自动动态化（图片转视频）；
- 选择视频模型，异步提交 `/api/ai/video` 或 `/api/ai/video/task`；
- 在“制作控制台”维护视觉圣经、创作意图、模型路由、质量门禁和修复。

只有这条链路真正会让每个镜头变成视频片段，再进入合成。它能满足“有动态、有角色/场景约束、可控音色”的需求，但入口隐藏在脚本之后的素材页，不在创建时表达成本、时长与模型选择。

### 3.3 原生整片链路：一次性模型成片

脚本/素材页还存在“一键整片 / storyboard-film”能力：先准备分镜网格，再向支持参考视频的模型提交一次整片任务。此类模型可以返回原生运动和原生音频。

它和逐镜动态生成、普通 FFmpeg 合成并列存在，却没有一个统一的“本次出片策略”选择页。导出页因此可能同时出现：

- 原生整片；
- 常规合成；
- 预览/重渲版本；
- 其他派生版本。

用户很容易误选“常规合成”，然后误以为豆包视频没有动态。

## 4. 配音入口与降级机制

| 位置 | 行为 | 当前问题 |
|---|---|---|
| 设置 → 配音 | 配置火山语音 V3、资源 ID、模型、音色 ID、语速 | 是正确的全局配置入口，但和视频页实际采用的策略没有显式绑定说明 |
| 视频页 → 合成设置 | 开/关 TTS；已配付费 TTS 时使用配置，否则回退 Edge 免费音色 | 用户不容易知道本次会用付费火山还是 Edge 免费音色 |
| 自动免费流水线 | 固定请求 `freeTts: { enabled: true }` | 即使配置了火山语音，首页默认快剪仍会绕过它，导致音色/质量与预期不一致 |
| 原生整片 | 依赖视频模型是否原生带音频 | 不会走设置页的 TTS；若没有明确提示，用户会误以为“配置没生效” |

普通合成中，付费 TTS 失败会尝试 Edge 免费 TTS；两者都失败时当前实现允许合成继续完成，仅将该镜头写入 `tts_failed` 警告。这解释了“某些镜头无声、音频断断续续”的现象。

**应改成产品规则而不是隐式兜底：** 在出片前明确显示“本次音频来源”，并让用户选择“失败即阻断”或“允许回退免费音色”；成片详情必须逐镜展示实际音源和失败原因。

## 5. 风格为什么会变成“痛点种草”

脚本接口接受 `styleType`。当选择“智能推荐 / auto”且历史转化数据不足时，后端的默认映射是：

```text
auto → pain_point
```

若有历史指标，系统会尝试用该品类/全局的高转化风格覆盖 `auto`；但冷启动时仍回到 `pain_point`。这意味着“智能推荐”在没有数据的项目中并不是真正的智能选择，而是“痛点种草”的别名。

建议：

1. 将“智能推荐”改名为“按历史数据推荐”；没有足够数据时提示“暂无数据，请明确选择风格”，不要静默落到痛点种草。
2. 新建项目默认明确选中一个中性风格（例如产品特写/场景安利），而非 `auto`。
3. 在脚本页顶部持久展示并可修改：本次使用的风格、受众、平台、语言/语气、视频策略、音频策略。

## 6. 创作控制为什么分散在“主页”和“制作控制台”

目前参数按实现时间被分到了三个阶段：

| 阶段 | 能控制的内容 | 主要缺口 |
|---|---|---|
| 创建前（`/project/new`） | 商品、受众、平台、脚本风格、视频模式、模板、角色 | 首页没有同等入口 |
| 脚本后/素材前（`/project/[id]/assets`） | 单镜描述、镜头、画面模型、I2V、动态强度、连贯性 | 用户创建项目时不知道后面还要设置这些 |
| 制作控制台（`/project/[id]/production`） | 创作意图、视觉圣经、工作流开关、模型路由、质检、修复 | 入口藏在素材页；且这些意图不会回写重生脚本 |

“创作意图”和“视觉圣经”属于项目级约束，应当在同一份创作简报里初始化，并贯穿脚本、素材、视频和合成，而不是等脚本已经生成后再单独补填。

## 7. 仍未清理的 Atlas Cloud 残留

虽然当前产品约束为“只使用火山/豆包和速创”，源码中仍能找到 Atlas 相关内容：

- 工作台内的 Atlas Key 一键接入弹层；
- 设置页的 Atlas 平台卡、一键配置与推荐文案；
- 脚本/复刻提示中的 Atlas 推荐；
- Atlas Provider、动态模型目录、TTS 兼容分支、README 宣传；
- 对 Atlas 配置的历史迁移与测试。

这不是单纯的文案遗漏：工作台会在未配置 LLM 时主动触发 Atlas 接入流程。因此应将其列为 **P0 范围收敛**：从用户界面、默认值和新手引导中彻底移除；保留或删除底层兼容代码则另行决策，但不得让它影响当前产品的默认路径。

## 8. 整改建议与优先级

### P0：先让每次出片“可解释、可预期”

1. **设定唯一的主创建入口。**
   - 主入口采用“创作简报”：商品 + 风格 + 人物/处境 + 场景 + 语言/语气 + 受众/平台 + 时长 + 视频策略 + 音频策略。
   - 首页展示简版，点击“展开创作要求”使用同一组件/同一请求体；不再维护第二套表单。
   - `/project/new` 改为主入口的完整视图或重定向，不能再有独立创建逻辑。

2. **把输出策略前置且命名清楚。**
   - `免费草稿`：静态素材 + FFmpeg，明确标注“非 AI 动态视频”；
   - `导演可控成片`：逐镜 I2V + 统一 TTS + FFmpeg 合成；
   - `原生整片`：一次模型生成，自带运动/音频，控制性较低。
   - AI 模式默认不得悄悄降级为免费草稿。

3. **删除面向用户的 Atlas 入口。**
   - 设置、首页、文案、错误提示统一只展示火山/豆包与速创；
   - 清理工作台的 `applyAtlasOneKey` 调用和默认引导。

4. **固定风格选择语义。**
   - “智能推荐”无数据时必须提示并要求选择，不能自动变成痛点种草；
   - 成片详情显示真实的 `styleType` 和来源（用户选择 / 模板 / 历史数据推荐）。

### P1：让创作约束贯穿全链路

1. 项目创建时保存一份 `creativeBrief`：人物、处境、场景、语言、语气、禁忌、受众、平台、利益点和风格。
2. 脚本生成、素材提示词、I2V 提示词、TTS 情绪指令均从同一份 `creativeBrief` 读取。
3. 制作控制台变成“项目创作设置”抽屉：从脚本、素材、视频页都可进入；不再是仅素材页可发现的孤岛。
4. 生成/导出版本明确分组：原生整片、逐镜动态合成、免费草稿，默认展示用户本次选择的主版本。

### P2：降低操作负担

1. 产品库、主播库、媒体解构、爆款复刻保留为“素材/灵感工具”，回填同一份创作简报，而不是各自创建不同形态的项目。
2. 批量出片复用单项目的同一脚本与出片策略，只增加批量调度/变量矩阵。
3. 在项目详情增加“生成追踪”：脚本模型、图片模型、视频模型、TTS 来源、是否发生降级、每一镜的素材类型（图/视频）与任务 ID。

## 9. 推荐的信息架构（目标态）

```text
MainPG → AI 视频
  ├─ 工作台（唯一创建入口）
  │   └─ 创作简报：基础信息 + 展开高级创作要求
  │       ├─ 脚本策略：明确风格 / 有数据时的推荐
  │       ├─ 视频策略：免费草稿 / 导演可控动态 / 原生整片
  │       └─ 音频策略：火山 TTS / 原生音频 / 静音
  ├─ 项目详情
  │   ├─ 脚本（可审、可重生）
  │   ├─ 素材与动态（逐镜）
  │   ├─ 制作设置（全局创作约束、模型、质检）
  │   └─ 成片与导出（只突出本次主版本）
  └─ 素材与灵感工具
      ├─ 商品库 / 主播库
      ├─ 爆款复刻 / 媒体解构
      └─ 批量出片
```
