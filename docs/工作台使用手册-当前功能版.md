# MainPG 本地工作台使用手册

版本：V1.0    适用：本地工作台（MainPG）

## 一、系统简介

本工作台是面向跨境电商卖家的本地工作台，覆盖选品采集、产品处理、核价货源、利润活动与产品库管理，并通过 AI 中转能力提供文本与生图服务。

工作台为本地运行（默认地址 `http://127.0.0.1:8010`），登录后使用。主要模块分布如下：

- **工作台**：任务概览与首页快捷入口；
- **产品处理**分组：采集、AI处理、历史记录、尺寸画布；
- **POD定制**：批量生成 POD 图片与标题并导出店小秘文件；
- **核价及货源**分组：核价/货源匹配、利润活动、货源关联产品库；
- **个人中心**：账户资料、积分钱包、充值订单与服务器账本安全状态。

本手册按实际业务流程编写，建议按章节顺序使用：

1. 注册并登录工作台；
2. 通过「工作台」首页快捷入口进入各模块；
3. 使用「采集 → AI处理 → 核价/货源匹配 → 利润活动 → 产品库」的完整流程。

> 说明：顶部顶栏支持多标签切换，可同时打开多个面板（如采集面板、处理任务、预检、尺寸画布），方便多任务并行。

## 二、注册与登录

### 1. 打开系统

在官网 `https://workbench.haocoming.top/` 下载安装包，安装完成后启动本地工作台，浏览器会自动打开工作台地址（默认 `http://127.0.0.1:8010`）。

[图片]

### 2. 注册账号

点击登录页的「注册」切换到注册表单，按以下要求填写：

- 用户名：填写你的用户名；
- 邮箱：填写可用的邮箱地址；
- 验证码：点击「获取验证码」，填写邮件收到的验证码；
- 邀请码：填写邀请码（必填）；
- 密码：设置登录密码（至少 8 位）。

填写完成后点击「注册并进入工作台 →」。

[图片]

### 3. 登录

注册成功后如需重新进入，在登录页输入注册时的账号（用户名或邮箱）和密码，点击「登录并进入工作台 →」。若忘记密码，可点击「忘记密码」通过邮箱验证码重置。

[图片]

## 三、AI 能力与密钥

工作台的文本 AI（标题、卖点、描述、翻译等）与生图 AI（四宫格、详情图等）能力由**服务端统一托管**，采用运营转售模式。

1. 购买密钥：通过 `https://station-88.aicoming.top/` 注册/登录并购买「文本模型 API Key」与「生图模型 API Key」，妥善保存。

2. 密钥托管：已购买的密钥由平台/运营统一在服务端配置，**用户侧无需也不应在工作台内填写模型 API Key**，避免自行配置导致串账。

3. 确认配置：如工作台提供「系统配置」页，其为只读状态页，仅展示「AI 服务密钥 · 服务端托管」，用于确认配置已生效。

4. 积分计费：使用 AI 处理、生图等能力时按积分冻结/结算（每次处理按链接数量冻结积分），余额与充值订单可在「个人中心」查看。

## 四、每日选品

每日选品用于采集候选商品并确认入池。进入「采集」模块，默认展示「模板预设」与「采集工作台」两个视图。

### 1. 模板预设

「模板预设」用于管理采集方向：

- 系统提供 24 个系统预设方向（如家居收纳、厨房餐饮、清洁日用等平台趋势补充），每个预设展示站点（US/CO/EC）、关键词、关注属性、价格范围、目标候选数等；
- 支持「＋ 添加预设」「更改预设」「删除预设」；也可点空白卡片自定义预设；
- 预设字段：预设名称（必填）、站点（美区/哥伦比亚/厄瓜多尔）、关键词（1–5 个）、关注属性（必填）、最低价/最高价（元）、每词候选数、卡片颜色。

[图片]

### 2. 采集工作台

「采集工作台」提供 3 个采集入口：**每日选品 / 整店采集 / 插件采集**。

#### 2.1 每日选品（API 采集）

- 采集方式：「关键词采集」（输入 1–5 个关键词）或「参考图采集」（填写可公开访问的参考图 URL，用于图搜）；
- 平台：1688 / 淘宝 / 1688+淘宝；
- 站点：美区 / 哥伦比亚 / 厄瓜多尔；
- 选品范围：发散相似款 / 精准匹配；
- 采集数量：目标候选数；
- 高级设置：最低/最高价格、起订量上限、SKU 规格数、SKU 最低/最高价、SKU 库存、采集并行数（1–10），以及「自动排除高风险候选」开关；
- 点击「开始采集」，采集过程中可「中断采集」。

[图片]

采集完成后，候选商品展示在下方「候选商品」区域：

- 可按 SKU 数量「筛选」；点「最近批次」查看历史采集批次；
- 对候选卡片可点「排除并反馈」剔除不要的商品；图片经本地代理加载；
- 勾选要保留的候选商品（可「全选」），点击「确认入池（N）」确认，确认后的商品进入产品处理草稿池。

[图片]

#### 2.2 整店采集

- 输入 1688 店铺主页 / 商品链接 / 商品ID（支持 `sid:123456` 写法）；
- 点击「开始整店采集」，左侧批次列表、右侧批次进度条实时显示；
- 统计：已发现 / 成功 / 失败 / 新建草稿；
- 操作：暂停 / 继续 / 重试失败项 / 取消。

#### 2.3 插件采集（1688 插件 · 万邦 API）

- 展示批次列表与统计（总数 / 新建 / 刷新 / 跳过 / 失败 / 未处理）；
- 先在插件侧登记链接，再在工作台点击「启动万邦采集」/「重试失败项」；
- 商品列表支持「查看来源」，以及「打开产品处理 · 草稿#N」。

### 3. 安装并连接浏览器插件（选品与核价共用）

每日选品与核价采集依赖浏览器插件「TEMU Y2 AI Workbench Connector」。

1. 下载插件：在官网下载「W-H-浏览器采集插件」，解压成文件夹（如 `W-H-browser-extension-v0.1.130`）。

[图片]
[图片]

2. 安装插件：
   - 打开浏览器的「扩展」管理页；
   - 开启「开发人员模式」；
   - 点击「加载解压缩的扩展」，选择解压后的 `W-H-browser-extension-v0.1.141` 文件夹；
   - 安装完成后，扩展工具栏中出现插件图标。

[图片]

3. 连接插件：先用浏览器打开 `http://127.0.0.1:8010` 登录工作台，并保持登录后的页面处于打开状态；然后点击浏览器工具栏中的插件图标，在插件面板中确认：

   - 工作台地址：`http://127.0.0.1:8010`（固定为本机地址，无需修改）；
   - 插件不再需要连接码：点击「连接插件」后，插件会自动读取工作台当前的登录状态完成连接（工作台重启后若连接失效，重新点击「连接插件」即可）；
   - 连接成功后，插件面板显示「公司 001 · 已连接」（公司更多时按 `127.0.0.1:8010/t/{三位公司编号}` 区分）。

[图片]

4. 插件采集入口：连接成功后，在平台页面（TEMU / 1688 / 淘宝 / 拼多多 / Amazon 等）点击插件图标或页面按钮：

   - **采集到工作台**：商品详情页单品采集，结果自动进入产品处理草稿池；
   - **批量采集本页**：列表页批量采集；
   - **采集核价本页**：TEMU「批量查看并确认申报价」页面核价采集（详见第六章）。

## 五、产品处理

「AI处理」模块用于管理草稿池、配置处理参数并执行商品资料处理，最终产出可导入店小秘的商品表。包含草稿池、处理任务、历史记录、预检与最终导出、尺寸画布。

### 1. 草稿池

草稿来源：每日选品「确认入池」、核价模块「保留 · 入草稿池」等。进入后即可看到草稿列表。

[图片]

- 顶部统计：待处理 / 已勾选 / 未保存；
- 使用搜索框（标题/SKC/SKU/来源）、SKU 数量筛选、「不看单规格」开关、「只看已选」视图定位草稿；
- 勾选要处理的草稿（一次最多 100 个）；
- 草稿卡片支持：勾选、切换「精品」（4K 智能生图拆四张）、上传/替换主图、编辑、复制、删除；
- 可点「管理 SKU」打开 SKU 抽屉，查看/编辑各规格图与属性、组合名称，删除/恢复 SKU；
- 可点「批量管理 SKU」批量管理；
- 用「保存已选」或「保存全部修改」保存修改；「删除选择」可从池中删除。

### 2. 开始处理

点击「开始处理」进入处理任务页：

- **处理设置**：站点（美区/哥伦比亚/厄瓜多尔，语言随站点切换）、语言（en/es）、生图模板（A 标准商品海报 / B 高端模特视觉 · 防比价），可定制提示词；
- **处理范围**：标题、详情、产品尺寸、四宫格、详情图、SKU图、资质；
- 按需开启「生成商品视频」「跳过已处理」「侵权词过滤」（IP 检查）；
- 设置处理数量与最大并行；
- 点击「开始处理」，页面实时显示处理进度（可「清空任务」「暂停/继续」「取消任务」）。

[图片]

处理结果与下载：

- 完成后显示结果汇总（总数 / 成功 / 失败 / 跳过 / 待确认 / 技术可重试 / 配置阻断）；
- 「失败商品」表格可查看失败明细，支持「重新处理」「查看明细」「重试全部失败（N）」；
- 下方提供下载：店小秘导入表（dxm_import.xlsx）、错误报告（csv）、视频清单（csv）；
- 可点击「预检并导出最终版」进入预检，完成预审后再导出最终版表格。

### 3. 历史记录

- 按日期范围筛选（起始/结束），支持清除、刷新；
- 顶部统计：处理中 / 已完成；
- 批次列表展示标题、状态、目标站点/语言、共/成功/失败/跳过、耗时、创建时间；
- 操作：「继续查看」，满足成功数条件时可「进入预检」。

### 4. 预检与最终导出（进入预检后）

- 商品卡片中可修改标题、产品描述、核心字段（SKU货号 / 申报价格 / 建议售价 / 库存 / 类目路径 / 类目ID / 物流包裹长宽高 / 重量，带来源徽章）；
- 核心字段支持「添加尺寸图」（跳转尺寸画布）；图片管理器可添加/预览/重试主图、轮播图、详情图、素材库、语义图；
- 可「删除」商品，被删商品进入「已排除的商品」区，可「恢复/全部恢复」；
- 点击「保存预检修改（N）」保存，点「完成预审并导出」依次生成表格 → 修改 → 导出最终版 → 导入店小秘，失败可「重试」，并可「下载最终版表格」。

### 5. 尺寸画布

- 通过「导入已完成任务」导入需要制作尺寸图的任务；
- 编辑器支持尺寸线、标注、单位切换、缩放、撤销重做，自动保存；
- 操作：完成并下一条、交回审核、重试渲染；队列面板可查看待处理任务。

## 六、核价及货源

通过浏览器插件采集 Temu 核价数据，人工审核后保留商品，并匹配 1688 货源。页面分 STEP 01 / 02 / 03 三步，以及「已关联货源」。

1. **数据采集（浏览器插件）**：使用与选品相同的插件，打开 Temu「批量查看并确认申报价」页面，点击插件「采集核价本页」（每页最多 50 个 SKC），报价自动入库；回到「核价/货源匹配」页自动加载批次（或点 STEP 01「刷新」）。

[图片]

2. **STEP 01 数据初筛**：可输入「调整后申报价（CNY ≥）」门槛、店铺（可选）、入库商品标识（SKC/SKU/SPU），点「仅保存」或「保存并进入批次审核」，后台按条件过滤，初筛后的 SKC 进入人工确认。

[图片]

3. **STEP 02 选择并图搜**：表格中勾选要保留的 SKC（可「全选」），可「复制 SKC ID（N）」；点「删除选中（N）」删除不需要的 SKC（删除后不可恢复）；点「确认并执行图搜（N）」进入货源关联。

[图片]

4. **STEP 03 货源关联**：
   - 点「执行图搜（N）」/「重新图搜」获取候选货源，候选卡带决策标签（推荐 / 待核 / 需验 SKU / 证据不足）、万邦图搜排名/本地相似度/销量、价格；
   - 对候选可调整「候选源价 / 重量」实时重算利润（显示调整后申报价 / 总成本 / 净利润 / 利润率，达标 / 未达标）；
   - 选中满意货源后点「关联」；也可「手动查 1688」输入链接添加候选；
   - 点「完成关联（N）」完成本批关联。

[图片]
[图片]

5. **已关联货源**：核对已关联的 1688 货源，如需更换可返回上一步或点「解除」。关联结果会同步到「货源关联产品库」。

## 七、利润活动

核算单品利润、保存产品资料，并生成活动申报与剔除结果。

### 1. 单品利润与入产品库

- 选择店铺（可选）、站点（美区/哥伦比亚/厄瓜多尔），填写商品ID（支持 SKU/SKC/SPU）、售价、成本、重量（KG）；
- 上传商品主图（支持 Ctrl+V 粘贴或选择图片）；
- 填写货源链接，并为每个货源链接上传对应的货源图（可「新增货源」多条）；
- 填写备注；
- 系统自动预览利润（总成本 / 毛利润 / 净利润 / 利润率），可「手动刷新预览」；
- 点击「入产品库」保存（必填：商品ID、售价、成本、重量、主图、每个货源链接的货源图、备注）；也可「一键清空」。

[图片]
[图片]

入库后产品即加入数据库，可在「货源关联产品库」中查看。

### 2. 产品资料导入（首次使用把已上架产品导入产品库）

- 点击「产品资料导入」，选择产品资料 Excel（支持多选 `.xlsx/.xlsm`），可填店铺、按「导入规范」核对；
- 点「预览入档」查看导入预览；
- 点「确认导入」，同 SKC 的商品按冲突策略替换或跳过更新。

[图片]

### 3. 活动过滤

- 在「活动过滤」上传活动 Excel（含 SKC/SKU/SPU）；
- 设置活动申报门槛：活动最低实际利润（元）、活动最低利润率（%），可「保存设置」/「恢复默认设置」；
- 点击「产品过滤」，确认是否过滤指定站点产品；过滤在后台异步执行，可点「暂停过滤」；
- 完成后显示可申报 / 剔除统计，可查看「历史过滤结果」；
- 点「生成并下载可申报产品」下载可申报文件；点「下载剔除产品」下载剔除文件；无满足产品时提示「没有可申报的产品」。

[图片]

### 4. 设置保存目录

- 可「设置保存目录」：本地保存目录；按站点 Tab 配置站点费率（头程每 kg、头程固定费、国内操作费、运费补贴、补贴售价上限（EC）、尾程固定费、退款率%）；支持「+新增站点」；「保存设置」/「恢复默认设置」。

## 八、产品库（货源关联产品库）

查询、维护并下载利润活动产品档案。

### 1. 查询产品

- 输入「商品ID」查询（支持 SKU/SKC/SPU，支持换行、空格、逗号批量）；
- 选择店铺（全部/未填写/具体店铺）、地区（全部站点/美区/哥伦比亚/厄瓜多尔）；
- 选择查询范围（手动 / 核价 / 核价+手动）；
- 点「查询产品」，留空展示全部；点「刷新」重新加载。

### 2. 行内编辑

- 站点、店铺、商品ID、售价、成本、重量、备注、商品图、图片可在单元格就地编辑；
- 修改后按回车或点「保存」即时保存，点「撤销」还原；商品图支持 Ctrl+V 粘贴自动保存。

### 3. 图片与货源

- 商品对应图：点「上传/替换」或 Ctrl+V 粘贴主图，自动保存；
- 货源：点「打开（N）」查看该商品ID关联的 1688 货源；核价入库产品可调整候选源价/重量并重算利润、解除关联；其他产品可点「修改」编辑图片与链接后保存。

### 4. 下载与删除

- 点「下载产品档案」：按勾选的站点合并为一个 Excel 文件下载；
- 勾选商品后可「复制已选商品ID」「批量修改店铺」，点「删除已选（N）」确认后删除（删除后不可恢复）。

## 九、补充说明

- **首页快捷入口**：工作台首页提供「应用」快捷入口，包括每日选品、AI 产品处理、历史记录、尺寸画布、核价匹配、利润活动、产品库；「继续处理」区可直接打开产品处理与货源产品库。

- **多标签切换**：顶部顶栏支持多标签切换，可固定/取消固定，便于同时处理采集、处理任务、预检与尺寸画布。

[图片]

- **个人中心**：查看账户资料、积分钱包、充值订单与服务器账本安全状态；余额不足时需先充值再使用 AI 处理等计费功能。

- **积分计费**：产品处理按处理链接数量冻结积分（默认 40 积分/链接），处理结束后结算；积分不足或未配置 AI 服务时后台会提示 AI 配置/额度与远程服务异常相关错误。
