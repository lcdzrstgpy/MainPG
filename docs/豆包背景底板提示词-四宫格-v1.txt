背景底板提示词 v2（分 5 批，每批一条 2×2 四宫格）
=========================================================================
怎么用
-------------------------------------------------------------------------
1. 一次只发一批（一条消息），等出图、检查、切图、命名完，再发下一批。
2. 每条都是自包含的：风格、光照、四格布局、禁止项全写在里面，不需要再补上下文。
3. 出图后**不用手工切图**：把 5 张四宫格存到桌面（保持原名 Temu上架白底图要求.png / 要求1..4.png），
   在 local-runtime 目录执行：
       python devtools/prepare_backgrounds.py
   脚本会：裁掉底部「豆包AI生成」水印（裁底部 9% 再等比拉回，木纹/水磨石上也不会留下涂抹痕迹）
   → 切四象限 → 统一 1200×1200 → 按 id 命名存到 web-frontend/public/assets/backgrounds/*.jpg。
4. 哪一格不合格，就把该条里 "a 2x2 grid of four equal square cells" 改成
   "one single square product-photography backdrop"，只留那一格的描述，单独补一张；
   补的那张单独裁好、按 id 覆盖同名 jpg 即可。

通用要求（已写进每条提示词，这里给你核对用）
-------------------------------------------------------------------------
- 四格等分、互相独立，不要分隔线、不要白边、不要拼贴缝；
- 每格都是空的：无产品、无道具、无植物、无家具、无手、无人、无文字、无水印；
- 平视机位、无夸张透视；5200K 柔和日光，左上主光、右侧补光，低反差；
- 每格底部约 15% 轻微压暗，形成柔和的落地影，方便后面贴产品；
- 材质细节清晰、渐变平滑（不要色带），不要暗角，不要人为光斑（节庆两格除外）。

每批自查（出图后 30 秒过一遍）
=========================================================================
1. 四格是否真的等分、没有分隔线 / 白边 / 拼贴缝？
2. 每格是否真的空？常见误入：杯子、托盘、花枝、椅子、边框文字。
3. 四格明暗是否一致？不能一格偏黄一格偏蓝。
4. 每格底部有没有柔和的落地影？没有的话贴产品会像“飘”在图上。
5. 切出来是否 1:1、长边 ≥1200px、边缘没有残留的邻格内容？
6. 有不合格的格子，单独补一张（见文件开头的做法），不要整批重出。
