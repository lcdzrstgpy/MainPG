# 品类场景与零件提示词库 v1（场景 + 零件组装版）

> 目标：把「场景」和「零件（陈设道具）」从一次性提示词里拆出来，做成可复用的资产；
> AI 处理时先用主体识别的品类，取该类别的场景槽 + 零件槽，拼成一条短提示词。
>
> 分类 id 与代码一致：`local-runtime/wh_local/modules/product_processing/domain/category_image_presets.py`
> 与前端 `web-frontend/src/modules/product_processing/data/imageCardOptions.ts`（12 类 + `general` 兜底）。
>
> 术语约定：
> - **场景件（scene）**：台面/背景/景深，决定画面第一眼的“生活感”。
> - **零件（prop）**：摆放在主体旁边的独立陈设物，可单独生成 PNG 素材。
> - **产品配件（accessory）**：属于商品本体的一部分（如杯盖、背带），**不能**当零件生成，也不能在提示词里另描述。

---

## 一、三条硬约束（先看这个，后面的都围绕它）

1. **每个品类只有 1 个主场景 + 1 个备用场景，零件最多 3 个。**
   零件超过 3 个，模型注意力被分散，且总提示词必然超预算。
2. **零件不重复、不叠词。** 同一材质只出现一次（有亚麻布就不再写“棉布/织物”），
   同一功能只保留一个（垫高件、承载件、点缀件各一），主体已有的形态不再做零件。
3. **词预算（英文单词）**：

   | 段位 | 上限 | 说明 |
   |---|---|---|
   | 场景段 `Scene:` | ≤ 12 | 台面 + 背景 + 景深，不写光 |
   | 零件段 `Set:` | ≤ 12 | 3 个零件，每个 ≤ 4 词 |
   | 品类段合计 | ≤ 26 | 场景 + 零件，其余交给五层卡片库 |
   | 最终整条 prompt | ≤ 70 | 含 wrapper 与 L1-L5 卡片 |

   超预算时的降级顺序：先删零件 3，再删零件 2；场景不动（场景缺失会让图回到“白底摆拍”）。

## 六、拼装规则（写进代码）

```text
最终品类段 = "Scene: {scene}; Set: {prop1}, {prop2}, {prop3};"
```

- 顺序固定：场景 → 零件 1 → 2 → 3；模型对前半段权重更高。
- 零件为空时整段省略，不留空 `Set:`。
- 不使用 `{}` 之外的占位符；不使用中文；不换行。
- 只允许 3 个零件；`Set:` 段超过 12 词就丢最后一个。
- 与既有 `CATEGORY_IMAGE_PROMPTS` 的关系：**替换**其中的 `Scene:` 段，
  `Focus / Show / Avoid` 仍保留（那是品类卖点与禁区，不是场景）。

### 6.1 成品示例（英文单行 + 词数）

`home_kitchen`（场景 10 词 + 零件 8 词）

```text
Scene: warm oak countertop, warm gray plaster wall, shallow depth; Set: walnut cutting board, white ceramic dish, eucalyptus sprig;
```

`apparel_accessories`（10 + 8）

```text
Scene: pale oak bench, warm white wall, shallow depth; Set: oak hanger, washed linen cloth, brass clip;
```

`hand_tools`（9 + 9）

```text
Scene: oiled workbench, gray pegboard wall, mid depth; Set: pegboard square, light oak block, warm gray stone slab;
```

`general`（10 + 7）

```text
Scene: warm gray plaster corner, neutral paper backdrop, shallow depth; Set: light oak block, washed linen cloth, stone slab;
```

## 七、四格轮换（同一零件集，四种摆法，不额外加件）

| 格位 | 卡片 | 零件用法 |
|---|---|---|
| 1 主图 | `frame_hero` + `frame_flatlay`（白底） | 只场景，**不上零件**（主图必须干净） |
| 2 细节 | `frame_macro` | 只场景，零件全部撤掉，画面留给纹理 |
| 3 生活场景 | `frame_environment` | 3 个零件全上，允许部分入画（露出 40%-70%） |
| 4 平铺 | `frame_flatlay` | 3 个零件全上，严格网格排布，主体居中 |

> 这样一批图里零件只“出现两次”，既保证成套感，又不会每格都堆满小物。

6. 零件素材落地到 `web-frontend/public/assets/props/{prop_id}.png`，`propCardLibrary.ts` 里把占位 SVG 换成 PNG，
   `imageUrl` 和匹配逻辑都不用动。

## 十、质检清单

1. 每个品类的 `Set:` 是否 ≤ 3 个零件、≤ 12 词。
2. 场景段是否 ≤ 12 词，且没有写光位（光归 L2 卡片）。
3. 零件之间是否同材质/同功能重复（例如同时出现 `linen cloth` 与 `kraft paper` 可接受，两个织物则不行）。
4. 主体材质/颜色是否触发替换规则，替换后是否仍 ≤ 3 件。
5. 最终整条 prompt 是否 ≤ 70 词，且无换行、无 `{}`、无中文。
6. 是否误把「产品配件」（杯盖/背带/收纳袋）当零件写进 `Set:`。
7. 主图格是否确实没有零件；细节格是否确实只有主体。
