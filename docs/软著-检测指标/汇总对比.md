## 建议阈值（示例，需按真实样本校准）

- 页眉含「软件全称+版本号」、页脚含PAGE：布尔，缺失即标记。
- 文件横幅计数>2且前缀一致 → 机器拼接。
- 注释行占比<2% 或 >20% → 异常（真人3~15%）。
- 注释去重：重复注释行占比过高（如>30%）→ 套固定短语露馅。
- 注释贴合度：注释应能指代相邻代码符号；完全不相关=可疑。
- **不要仅凭“注释像人写的”放行**——注释是高风险规避点，需与命名、结构、说明书联合校验。
- 逐页有效代码行<50（严格口径）→ 不合规。
- TODO/调试痕迹==0 → ‘过度整洁’，纳入人工复核。
