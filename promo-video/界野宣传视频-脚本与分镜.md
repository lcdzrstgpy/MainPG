## 五、字幕规范

- 主标题字号 ≥ 84px（1080 宽画布内），保证手机端 3 米外可读
- 每屏文字不超过 3 行；单行中文 ≤ 14 字
- 关键数字（200 / 4 张 / 2048 / 2000×2000 / 42 列）统一用橄榄绿 `#a8b862` 强调
- 品牌名首尾出现 2 次即可，中间用左上角水印保持存在感

## 六、BGM 与音效建议

| 时间点 | 音效 |
| --- | --- |
| 0.0s | 低频 riser 起手，衬底垫音 |
| 3.0s | 品牌亮相：「叮」金属质感 + 一拍鼓点（配合米白闪屏） |
| 6.2 / 9.9 / 14.1 / 17.1 / 20.6 / 23.8s | 每次切镜一次 click/whoosh，卡在画面滑入的瞬间 |
| 数字出现处（200 / 4 / 42） | 短促「哒」提示音，强化数字记忆 |
| 26.6s | 音乐收尾 + 品牌落版长音 |

BGM 类型：中速电子鼓点（100–115 BPM），避免人声，避免版权曲库外的音乐。
