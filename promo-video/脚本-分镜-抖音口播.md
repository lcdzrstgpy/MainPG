## 四、剪映里的 6 步操作

**第 0 步（必做）**：先完全退出剪映，再跑生成脚本，然后重新打开剪映。
剪映在运行中退出时会回写草稿注册表，可能把新草稿的登记冲掉。

1. **打开草稿**：剪映 → 草稿列表 → `界野-抖音口播-60s`。首屏会看到两条文本轨：
   - 上轨 = 上方字卡（8 条，贴在画面上沿）
   - 下轨 = 口播稿（8 条，贴在画面下方，颜色偏绿便于区分）
2. **生成数字人**：选中下轨的文本素材 → 右侧「文本」面板 → 「数字人」→ 选你的定制形象 → 选克隆音色 → 生成。
   8 句逐条生成，数字人会按句出现在视频轨上、并自动吸附到对应时间点。
   - 若你更想一次成段：把 8 条文本按顺序拼成一段（分镜表第三列顺序拼接即可），只生成 1 次，再把生成的视频按分镜切分。
3. **把数字人摆到下半屏**：数字人默认铺满画布。选中数字人片段 → 「画面 → 基础」：
   - 缩放先设 **50%** 左右，再按你的定制形象构图微调（半身像建议 45–55%）
   - 位置 `Y` 往下拖，使其底边对齐画布下沿、头顶大致落在画面中线略下方
   - 确认右下角 320×420 区域干净（留给官网链接 / 二维码）
4. **补上方画面**：媒体 → 素材库 → 按分镜表第四列关键词检索 → 拖到视频轨、吸附到对应字卡时间段的起点 → 拉满上半屏（缩放拉到盖住画面上半屏，底部与数字人头顶自然衔接）。
   每镜一段，共 8 段；同一镜里可再切 1–2 个子画面提高留存。
5. **字卡收尾**：字卡轨拖到素材轨之上（保证不被画面盖住）→ 批量选中 8 条字卡 → 加描边（白字加 2px 深色描边，防浅色画面糊字）→ 关键数字（24 / 120 / 30 / 100 / 50 / 500 / 2000 / 200）单独改成橄榄绿 `#a8b862`。
6. **BGM 与导出**：音频 → 音乐素材 → 中速电子鼓点（100–115 BPM），音量压到 -18dB 左右（不要盖住口播）→ 导出 1080×1920 / 30fps / 高码率。

**字幕说明**：数字人自带口型，不需要额外字幕轨；抖音信息流大多数用户静音观看，**必须**保留上方字卡。若想加逐字字幕，用剪映「智能字幕」识别数字人音轨即可，字幕放画面下三分之一、字号 ≥84px（对齐《界野宣传视频-脚本与分镜.md》的字幕规范）。

## 六、避坑清单

1. **生成前必须退出剪映**，生成后再打开。剪映运行中会回写 `root_meta_info.json`。
2. **报「草稿内容已损坏」** → 跑 `python build_draft.py --alt`，改写入 `draft_info.json` 并把注册表指过去。
3. **草稿没出现在列表里** → 关掉剪映，重跑脚本，再开剪映；仍不行就手动在剪映里新建一个空草稿，改名成 `界野-抖音口播-60s` 再跑脚本（脚本按同名覆盖）。
4. **首次打开慢**：剪映 11.5 会静态探测到这是明文草稿并自动升级格式，属正常现象。
5. **字体路径**已写死为剪映 11.5 的 `Apps/11.5.0.14471/Resources/Font/SystemFont/zh-hans.ttf`。若剪映升级版本，路径会变，字卡会回退默认字体——在剪映里重新选一次字体即可。
6. **素材库素材**注意商用授权范围，推广投放前确认可商用。
7. **安全区**：上方字卡不要顶到 220px 以内；右下角 320×420 让开，别被数字人身体或字卡压住。
8. **数字人形象一致性**：同一条片子只用同一个定制形象 + 同一个克隆音色，抖音同一投放组内保持一致，便于算法归因。
